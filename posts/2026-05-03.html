OpenAI 连续错过营收与用户目标，CFO 与 CEO 现罕见公开分歧

《华尔街日报》报道，OpenAI 在 2026 年初多次未完成内部月度销售目标，同时距离年底达成 10 亿 ChatGPT 周活跃用户（WAU）的目标仍有差距，上次公开数据停在 8 亿。CFO Sarah Friar 私下表达了具体担忧：她认为公司在数据中心合同上的支出超出当前营收轨迹所能承受的范围，并希望强化支出纪律，这与 CEO Sam Altman 的扩张节奏产生了摩擦。Friar 还对公司的内部控制是否已达到上市标准存疑，而 Altman 明确希望年内实现 IPO。

AI 方向观点

Aaron Levie（Box CEO）：AI 不会消灭工程师，Jevons 悖论正在发生

Levie 提出了一个反直觉的思想实验：如果 AI 可以写大量代码，按理应该减少对工程师的需求。但他的论点正好反过来——软件越多，系统越复杂，遇到安全事故、停机或版本升级时需要处理的工程难题也就越多，所以需要的工程师反而更多，不是更少。"最有趣的概念是：我们写的代码越多，需要的工程师反而会越少——这根本是反的。因为系统的复杂度在提升，问题出现时你需要的人也会更多。"

这是 Jevons 悖论（Jevons paradox，历史上描述煤炭效率提升后反而消耗更多煤炭的现象）在软件工程上的直接应用。它与 Levie 此前关于"企业不应用降本框架思考 AI"的立场一脉相承：AI 让软件开发成本降低，但反而触发了更多软件项目立项——更多代码、更多系统、更多复杂性。AI 让软件工程师的工作量乘法，不是减法。

Sam Altman：我更想要更便宜更快的模型，而不是更聪明的模型

Altman 在 X 上写道："我一直在想，我更想让模型更便宜更快，而不是更聪明。"（"i keep thinking i want the models to be cheaper/faster more than i want them to be smarter"）这条推文字数极少，但立场清晰：下一轮 AI 竞争的核心变量，他认为是可及性（accessibility），而不是智力上限（raw capability）。

这与 OpenAI 最近的产品节奏一致——GPT-5.5 xhigh 在 fast mode 下提速，Codex 的服务成本也在持续下降。对 PM 和 builder 来说，这意味着能用的场景会继续扩张，但不是因为模型"更聪明"，而是因为调用成本下降到原来覆盖不了的场景也能负担得起了。Altman 把 AI 的下一步竞争点从能力赛转向了效率赛。

产品与商业

Max Schoening（Notion 产品负责人）：Agency 比 Skills 更重要；vibe coding 让软件更多但质量没变好

Schoening 的核心论点是：在 AI 时代，区分优秀者与落后者的不是技能（skills），而是主动性（agency）——愿意拿起新工具、主动推进事情的行动倾向。他把从 PM、设计师到工程师都在拿起 terminal 写代码这件事，归结为 agency 驱动的结果，而不是技能培训的成果。

"每个项目的前 10% 现在是免费的"——这句话指的是原型、方案草图、初步探索，以前是最难起步的部分，现在 AI 可以无成本帮你跨过。但 Schoening 同时指出，vibe coding（随手写随手扔的代码氛围）确实让软件数量爆炸式增长，但质量并没有同步提升，这个缺口反而是机会。

他的"tiny core"理论认为伟大产品都有一个极简核心交互：iPhone 是多点触控，GitHub 是 pull request，Notion 是 blocks，Dropbox 是菜单栏图标。这个核心不靠功能堆砌，而靠交互设计上的一次精确命中。Notion 他们把产品理念浓缩为"drive it like it's stolen"（开得像辆借来的车），意指毫无束缚地快速推进，不把历史包袱当借口。agency 是可以培养的，但前提是先承认技能清单从来不是你的护城河。

Crabbox 是 Steinberger 正在构建的开发者工具（以 GitHub 组织 openclaw/crabbox 发布），定位是"warm a box, sync the diff, run the suite"——租一台快速 Linux 机器，同步本地的未提交变更（dirty worktree，即包含未暂存改动的代码库状态），在远端运行命令，实时 stream 输出，完成后释放机器。0.3.0 版本的关键改进是支持 dirty worktree 的远程运行，修复了之前 npm 安装时的依赖问题和速度慢的 bug。

人文与哲学

纯银《羔羊计划》Vol.20260503：Vannevar Bush — 超文本与 Memex 想象的起点

今天这期《羔羊计划》的主角是 Vannevar Bush，一个今天很少被提起、但现代信息工具几乎都能追溯到他的人。1945 年，他在《大西洋月刊》发表了一篇题为"As We May Think"（如我们所思）的文章，提出了一个假想设备 Memex（记忆延伸器）——一张桌子，存储所有书籍、记录和通信，可以用机械方式快速检索，并允许使用者在不同内容之间建立"关联轨迹"（associative trails）。这不是科幻小说，是一份认真的工程构想。

超链接、个人电脑、搜索引擎，甚至今天 AI agent 的知识图谱，都在不同程度上实现了 Bush 七十年前画的图纸。他的判断是：人类的认知瓶颈不在于缺乏信息，而在于信息无法按照人脑的联想方式被检索和组合。这个诊断至今准确——我们现在讨论 RAG（检索增强生成）、记忆模块、agent 工具调用，本质上还是在解同一道题。

纯银把 Bush 放进《羔羊计划》的人物研究序列（目前进度 30/100），用意不难理解：在工具换代如此之快的时刻，理解工具背后的思想谱系，比追赶工具本身更有持续价值。Memex 没有被发明出来，但它的问题意识一直没有消失。

AI 进展

GLM-5V-Turbo：首个原生多模态 agent 架构，视觉从第一天就是基础

现状：主流多模态模型通常是先有语言模型，再把视觉能力"接上去"，视觉是附件而非内核。

问题：这种架构导致视觉理解与 agent 行动（工具调用、任务分解、GUI 交互）之间缺少深度整合，视觉信息难以自然地参与推理链。

解决方案：Zhipu AI（Z.ai）发布的 GLM-5V-Turbo 从架构设计阶段就把视觉与 agent 能力统一，搭配新视觉编码器 CogViT，通过跨 30+ 任务类型的强化学习（RL）训练，并使用 INT8 量化（一种减小模型体积、提升推理速度的压缩技术）部署。

价值：在多模态 agent 基准 MMSearch 得分 72.9，在网页代码还原基准 Design2Code 上超过 Claude Opus 4.6；视觉理解与工具调用的衔接比接插件式方案流畅。

未来方向：原生多模态 agent 架构（vision-first）很可能成为下一代 agent 模型的标配，视觉不再是选配功能，而是基础能力层。

HuggingFace · arXiv 2604.26752

Agent-World：自进化训练场，8B 模型在 23 个基准上超过专有模型

现状：训练强大的通用 agent 需要大量多样化的真实环境，但真实环境难以规模化获取，agent 常常在特定任务上过拟合。

问题：缺乏能持续生成新任务、暴露模型能力盲区的训练机制，导致 agent 能力天花板受限于已有数据集的覆盖范围。

解决方案：Agent-World 提出两个核心组件：(1) 自动从真实世界主题中发现可执行任务的探索机制；(2) 持续识别模型能力缺口、动态合成针对性任务的自进化训练 arena（训练竞技场），让 agent 策略与训练环境协同进化。

价值：Agent-World 训练的 8B 和 14B 模型在 23 个 agent 基准测试上持续超过更大的专有模型，验证了环境多样性与自进化轮次之间存在明确的 scaling 趋势。

未来方向：让训练环境与模型同步迭代，而不是固定数据集训练，是解决 agent 泛化问题的一条有力路线。

HuggingFace · arXiv 2604.18292

Agentic World Modeling：L1/L2/L3 能力分级框架，400+ 文献综述

现状："世界模型"这个术语在不同研究社区里含义不一，导致论文间比较困难，评估标准混乱。

问题：缺乏统一的分类框架，无法系统比较不同系统在不同能力维度上的进展。

解决方案：论文提出"能力级别 × 规律体系"双轴分类框架：能力分三级（L1 预测器、L2 模拟器、L3 自我修正进化器），规律体系分四类（物理、数字、社会、科学）；综述 400+ 文献，归纳超过 100 个代表性系统。

价值：为跨领域 agent 研究提供了统一语言，覆盖模型强化学习、视频生成、GUI agent、多 agent 社会仿真和 AI 科学发现等方向，并提出最小可复现评估套件。

未来方向：L3 级别（能在预测失败时自主修正自身模型）是当前最大的开放问题，也是 agent 走向真正自主的关键能力门槛。

HuggingFace · arXiv 2604.22748

The Amazing Agent Race：agent 擅长用工具，但不擅长导航 — 37.2% 是当前最高准确率

现状：现有工具调用基准测试大多是线性任务链（2-5 步），分析六个主流基准发现其中 55–100% 的实例都是简单顺序结构，无法测出 agent 在复杂路径上的真实能力。

问题：没有基准专门测试 agent 在有岔路和合并节点的任务图（DAG，有向无环图）中，能否正确规划和导航。

解决方案：The Amazing Agent Race（AAR）设计了包含岔路-合并工具链的 DAG 拼图，共 1,400 个实例（顺序型 800 + 组合型 600），要求 agent 在 Wikipedia 上导航、执行多步工具链并汇总答案，通过三个互补指标分别诊断导航、工具调用和计算失败。

价值：在三个 agent 框架上测试，最高准确率只有 37.2%，证实了标题所言：当前模型是"强工具用户，弱导航者"，工具调用能力与任务规划能力存在系统性落差。

未来方向：提升 agent 导航能力（规划、回溯、路径重组）是比工具调用更难啃的骨头，也是当前 agent 在真实复杂任务上失败的主要原因之一。

arXiv 2604.10261 · 项目主页

NS-Mem：神经检索 + 符号推理的长期记忆，提升多模态 agent 长任务准确率

现状：多模态 agent 在长任务中需要跨步骤记忆大量上下文，但纯神经检索（依赖向量相似度）在需要精确逻辑推断的场景下容易出错，而纯符号推理（规则引擎）又无法处理模糊的视觉输入。

问题：神经方法和符号方法各有盲区，单独用哪个都不够，但融合并不容易。

解决方案：NS-Mem（Neuro-Symbolic Memory）构建分层架构，神经检索负责从视觉和文本中提取相关片段，符号推理层通过显式逻辑规则和过程化 DAG（有向无环图，用于描述依赖关系的结构）对检索结果做精确判断，两个层次互补配合。

价值：在多模态 agent 长期记忆基准上显著提升准确率，在需要跨越多个推理步骤的任务中尤其明显，兼顾了灵活性（神经）和精确性（符号）。

未来方向：神经-符号混合架构可能是长任务 agent 记忆问题的系统性解法，比纯向量检索或纯规则引擎都更有扩展潜力。
