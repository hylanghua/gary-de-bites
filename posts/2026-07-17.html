月之暗面发布 Kimi K3：开源权重、2.8 万亿参数

Kimi K3 是月之暗面迄今最大的模型——2.8 万亿参数混合专家架构，支持 1M token 上下文，Apache 2.0 授权。在 Frontend Code Arena 对战平台以 76% 胜率超过 Claude Fable 5 和 GPT-4.5，夺得代码生成榜首。权重将于 7 月 27 日正式开放下载，API 已同步上线。这是继 Kimi k1.5 之后最具竞争力的中国开源模型，也是首个在国际基准上明确标榜击败 Fable 的开源模型。

人文与哲学

羔羊计划：John McCarthy 与 AI 最初的道德困境

纯银在小报童发表长文，回溯 John McCarthy（LISP 之父、「人工智能」命名者）1950 年代的一个思想实验——他设想是否可以让机器「自愿」承担危险任务，就像古代社会的「替罪羊」。文章从这个历史细节出发，讨论当 AI 足够智能时，「同意」与「被迫」的边界在哪里，以及我们今天训练 RLHF 模型时是否重演了同样的结构性困境。

小报童 / 纯银

Aditya Agarwal：「有价值」与「可分享」是两件事

前 Dropbox CTO Aditya Agarwal 在推文中指出，社交媒体时代让人们混淆了「对某人有价值」和「让很多人转发」——真正改变某个人生活的内容，往往是不会被广泛传播的私信或一对一对话。他将此延伸到 AI 产品设计：追求病毒式传播的功能和追求真正有用的功能，是两条不同的设计路径，经常相互矛盾。

AI 进展

SEED：让语言模型学会「何时停止搜索」

arXiv 2607.14769。现有 RAG 系统往往过度检索或检索不足。SEED 提出搜索终止感知训练框架，让模型在每一步推理后判断「已有信息是否足够回答问题」，而非固定检索轮次。在多跳问答基准上，SEED 将平均检索轮次减少 38%，同时 F1 提升 4.2 个百分点。

arXiv

SearchOS-V1：把搜索引擎变成 Agent 的操作系统

arXiv 2607.15257。研究者将传统搜索引擎重新设计为「Agent 原生操作系统」——不再返回网页列表，而是以结构化 JSON 工具调用的形式提供检索、摘要、实体解析等原子操作。在 WebArena 基准上比 GPT-4o + 标准搜索高出 11%，延迟降低 40%，因为减少了多次 LLM 解析网页的开销。

arXiv

WebSwarm：用群体智能解决复杂网页任务

arXiv 2607.08662。WebSwarm 部署多个专门化 Agent 子群（导航群、提取群、验证群），通过蚁群算法启发的信息素机制共享发现并避免重复探索。在 Mind2Web 测试集上任务成功率达 61.3%，比单 Agent 基线高 18 个百分点，尤其在需要跨多个标签页综合信息的任务上优势显著。

arXiv

下一代 Agentic RL：奖励稀疏时的长程规划

arXiv 2607.01120。研究聚焦强化学习在超长 horizon（200+ 步）Agent 任务上的失效问题，提出分层子目标分解 + 过程奖励模型的联合训练方案。在 SWE-bench Verified 上，经此方案微调的 7B 模型达到 34.1%，超过未经 RL 的 70B 模型，证明训练方式比模型规模更关键。

arXiv

自主信息寻求：Agent 何时该主动提问？

arXiv 2607.04433。论文系统研究「信息不完整时 Agent 应主动澄清还是推断执行」的决策问题，提出不确定度感知的主动提问策略：当任务完成概率低于阈值时触发提问，高于阈值则自主推断。在客服和代码生成场景中，该策略将用户打断次数减少 52%，同时任务成功率提升 9%。
