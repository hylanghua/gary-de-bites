AI 方向观点

Aaron Levie（Box CEO）：Claude Tag 的真正难点是 agent 身份与权限隔离

Levie 拆解了 Claude Tag 架构中常被忽视的细节：这不是"你的 Claude 扩展到了 Slack"，而是一个在团队工作空间里拥有自己身份（credentials，即访问令牌与权限凭证）的独立 agent。每位用户无法把自己的私有工具和数据暴露给这个共享 agent，否则任何人都能通过 Tag 间接读取；agent 需要像团队普通成员一样被单独授权——它能访问哪些销售资料、哪些产品路线图文档、哪些法务合同，必须在授权层面显式决定。

Levie 预判下一步：随着越来越多团队把 agent 接进企业内容与数据系统，"给 agent 开账号、设权限、做审计"将成为 IT 和安全团队的标配工作，而不是 AI 产品的附加功能。把 agent 当同事管理，而不是当工具使用，这个心智模型的切换才是企业 AI 真正落地的门槛。

AINews：Meta-Harness Summer — 元调度层（meta-harness）正在被 1000 家公司独立重新发明

Latent Space / swyx 的 AINews 将本周命名为"元调度层之夏"：在 Claude Code SDK、Cursor、OpenAI Codex 等各家 agent harness（调度框架，即管理多个 AI 的执行环境与权限系统）之上，正在出现 harness of harnesses——统一调度各家 agent 的更高一层编排系统。Databricks CTO Matei Zaharia 主导的 Omnigent 是目前最受关注的开源尝试：插件化架构、可接入任意 coding 或 knowledge work agent、内置安全与可靠性层。

AINews 的核心观察不是 Omnigent 本身会不会成功，而是这个架构模式正在被至少 1000 家 AI 原生公司独立重新发明——这意味着某种开源协调层的胜出已经不可避免，问题只是谁来定义标准。类比：MCP（Model Context Protocol）的成功有其架构必然性，元调度层也正走向类似轨迹。AI 基础设施的下一层抽象不在模型侧，在编排侧——这是今年最值得追踪的架构演化方向之一。

Meta 如何重塑 PM 角色：夜间 agent 取代信息压缩链条

Lenny Rachitsky 对话 Meta VP of Product Jagjit Chawla（负责 Facebook Feed、Reels 与 Search），核心洞察是：Meta 已经把 PM 工作的机械层完全 agent 化。Chawla 将过去的信息传递机制称为"压缩算法"：工程师知道 commit 的真相，经理提炼，到 VP 层已经是三手摘要。现在，一个 nightly agent（每晚自动运行一次的 AI 程序）直接扫描原始代码提交，告诉高管昨晚真正发生了什么，没有中间层。

PRD（产品需求文档）从几十页缩成一段话加一个原型，高管的周会从看团队准备的 deck 变成审阅 agent 写的文档。Chawla 的结论是：当想法变得廉价（ideas got cheap），判断好想法就成了 PM 最核心的工作，而 PM 正在变成整个研发流程的最大瓶颈。这些变化不是从总部颁布的，是各团队自己在一个晚上用现有工具搭起来的。当 agent 接管了信息传递，管理层的价值不再是"让信息流动"，而是"判断什么值得做"。

静止的量子 Vol.20260625：清华 DISH——3D 打印从"逐层制造"到"瞬间制造"

修饼介绍了清华大学最新发明的 DISH（Dynamic Illumination Simultaneous Holographic）3D 打印技术：不再一层一层堆积材料，而是从四面八方同时投射数千幅精确计算的光图案，让液态光敏树脂在 0.6 秒内于三维空间中同时固化。整个过程几乎没有机械运动，精度可达十几微米（比头发丝还细），因为液体始终保持静止，还能使用水凝胶等低粘度生物材料。

修饼把这个技术转变用一句话概括："过去是在二维平面上一层层堆出三维世界，现在是第一次真正实现了整个三维空间同时成型。"目前的限制：仅适用于毫米级小尺寸物体，距离工业级大尺寸还有距离。DISH 不是把 3D 打印做得更快，而是根本改变了"制造"这件事的时间逻辑。

AI 进展

OpenThoughts-Agent：agentic 模型训练数据配方，100+ 消融实验

现状：训练 agentic 模型（能在真实环境中执行多步任务的 AI）的数据来源分散，缺乏系统对比实验。

问题：不清楚哪类任务数据、哪种数据多样性、哪种训练规模策略对 agent 能力提升贡献最大。

解决方案：Stanford 团队开源了 OpenThoughts-Agent v2，整合完整数据筛选流水线，构建 100K 样本训练集并进行 100+ 受控消融实验，系统比较不同数据源、指令格式、执行轨迹长度对结果的影响。

价值：在 Qwen3-32B 上微调后，七项 agentic 基准平均得分 44.8%（对比最强现有开源数据集 Nemotron-Terminal-32B 的 40.9%，提升 3.9 个百分点），且在每个训练规模下均领先替代数据集。

未来方向：研究者称这是 DataComp/OpenThoughts 系列的延伸，将持续开放数据配方以支持开放 agentic 研究生态。

SafeSpec：把越狱攻击建模为分布偏移，在 speculative decoding 内实现安全与速度兼得

现状：LLM 推理加速常用 speculative decoding（推测解码，先用小模型草拟输出再用大模型验证）提升吞吐量，但安全防护与推理加速通常相互竞争。

问题：越狱攻击（jailbreak）会在输出分布上引入可检测的偏移，但现有防护机制要么拖慢推理，要么只在最终输出层介入。

解决方案：SafeSpec 将越狱信号建模为动态分布变化，在 speculative decoding 流程内部做风险感知的轨迹恢复，无需额外安全检查。

价值：在 Qwen3-32B 上，攻击成功率降低 15%，正常任务的推理速度仍保持 2.06x 加速——安全不以吞吐量为代价。

未来方向：将框架扩展到多模态推理场景。

arXiv 2606.19755

Agentic Collaborative Cognition：多 MLLM agent 协作实现零样本三维场景理解

现状：三维场景理解（3D scene understanding）需要整合视觉、空间推理与多视角信息，单一多模态大模型（MLLM，即可以同时理解图像与文字的 AI）难以覆盖所有维度。

问题：如何在零样本（zero-shot，不针对特定任务额外训练）条件下，利用现有 MLLM 完成三维理解？

解决方案：提出 Agent Collaborative Cognition 框架，让多个 MLLM agent 各自负责不同感知维度（空间关系、物体属性、场景结构），通过结构化协作与信息聚合完成整体判断。

价值：零样本场景下显著超越单模型基线，无需针对三维数据额外微调。

未来方向：扩展到具身 agent（embodied agent）的实时环境理解场景。

arXiv 2606.24649

Multi-Agent Fictitious Play：用博弈论框架让 LLM 多智能体决策迭代收敛

现状：多智能体系统（multi-agent system）中，多个 LLM 协同做决策时常陷入震荡或不收敛，缺乏理论保证。

问题：如何让 LLM 多智能体在对抗或协作场景中的决策行为具有可预测的收敛性？

解决方案：借用博弈论中的虚构博弈（fictitious play）机制——每个 agent 根据对手过去行为的历史分布更新自己的策略，逐轮迭代直至纳什均衡。

价值：在多种博弈任务上显示 LLM agent 可以通过此机制达到稳定策略，为多智能体 AI 系统的可靠性分析提供了理论抓手。

未来方向：应用于现实中的谈判、协商与资源分配 agent 场景。

arXiv 2606.19308

Memory for Autonomous LLM Agents：write-manage-read 循环与五类记忆机制综述

现状：LLM agent 的记忆能力（即在多轮任务中保留、检索、更新信息的机制）是 2026 年 agent 基础设施争论最激烈的层次之一。

问题：记忆的设计空间太分散，缺乏统一的分类框架和评估标准。

解决方案：本综述将 agent 记忆形式化为 write-manage-read 循环，整理五类核心机制：上下文压缩（context-resident compression）、检索增强存储（retrieval-augmented stores）、反思式自我更新（reflective self-improvement）、层次虚拟上下文（hierarchical virtual context）、策略学习管理（policy-learned management）。

价值：提供 2022–2026 年 agent 记忆研究的完整导航地图，并指出记忆应作为完整数据管理层（含存储/检索/更新/生命周期）来评估，而非仅靠端任务成功率判断。

未来方向：记忆正在从"上下文拼接"演进为异步基础设施——Weaviate Engram 等系统已将记忆提炼/去重/生命周期管理作为独立服务层。
