「并行研究 Agent 是科学计算基础设施」的方向叙事正在成型

GPT-5.6 Sol Ultra 被用于 64 个子 Agent（即并行运行的独立推理进程）并行协作，在不到一小时内声称生成了 Cycle Double Cover 数学猜想的证明——这一声明仍待外部验证，但 OpenAI 内部和外部社区都在主动推进这一叙事。与此同时，Sébastien Bubeck 分享了单人借助 GPT-5.6 完成 100 万行 Lean（一种数学形式化语言）形式化证明的案例。

在医疗方向，OpenAI 公布了一项涉及 20,000 条评分的盲评研究：在困难任务集上，医生评审员发现 GPT-5.6 回答的缺陷数少于医生本人写的回答。这两个方向——数学证明自动化和医学智能——被 OpenAI 刻意捆绑到「GPT-5.6 作为科研基础设施」的框架里。实验室的目标叙事正在从「AI 帮你干活」升级为「AI 替代人类作为科学计算的主体」，不管单个声明是否成立，方向已经对准了。

Latent Space / AINews

LLM-as-a-Verifier：反复采样 + 分数排序，在多个 Agent 基准上达 SOTA

近期研究提出「LLM-as-a-Verifier」框架：让 LLM 对同一任务反复采样多次，再用 score-logprob（即模型给出答案时的对数概率置信度）对输出排序，选出最可信的那个——不需要额外的监督训练信号，也不依赖人工标注的验证器。在 Terminal-Bench V2、SWE-Bench Verified（代码修复基准）、RoboRewardBench（机器人奖励建模）、MedAgentBench（医疗 Agent 评测）四个基准上均报告了当前 SOTA。

核心思路是：模型自身的概率分布已经包含了足够的「自信度」信号，可以作为低成本的质量代理指标。反复采样 + 自信度排序是 agent 评估里被低估的方向，成本极低，不需要额外模型，但要有足够的推理预算支撑「采样多次」。

Tim Ferriss 本周：Murakami 写作论、《Hi Ren》与「生命随勇气伸缩」

Tim Ferriss 的周五通讯以三个文化入口拼出了一个主题：勇气与创作的关系。他在开车和泡澡时听 Murakami 的《Novelist as a Vocation》（《职业作家》），引用了其中一句「小说家在创作一部小说时，同时也被这部小说创作着」。他重温了 Ren 的《Hi Ren》，称其为「天才、疯狂、哲学与救赎的混合鸡尾酒，歌词是纯粹的天才」。

核心引言来自 Anaïs Nin：「生命随一个人勇气的大小而收缩或扩展。」（Life shrinks or expands in proportion to one's courage.）另一条来自《被讨厌的勇气》：「你的不幸不能怪过去或环境，也不是因为你缺少能力，你只是缺少勇气——可以说，你缺乏幸福的勇气。」在 AI 加速的当下，「勇气不足」这个诊断框架特别值得内化，因为绝大多数停滞不是能力瓶颈，是行动瓶颈。

AI 进展

LLM-as-a-Verifier：反复采样 + 对数概率置信度排序

现状：Agent 评估通常依赖人工标注或额外的判断模型（Judge LLM），成本高且引入额外偏差。

问题：如何在不增加外部监督的前提下，让模型自己判断哪次输出最可靠？

解决方案：对同一任务反复采样多次，用 score-logprob（模型在生成答案时对每个 token 的对数概率之和，反映模型自身的置信度）对输出排序，选置信度最高的那个作为最终输出。

价值：在 Terminal-Bench V2、SWE-Bench Verified（代码 bug 修复）、RoboRewardBench（机器人奖励建模）、MedAgentBench（医疗 Agent）四个基准均报告 SOTA，无需额外训练。

未来方向：随着推理成本下降，反复采样的边际成本趋近于零，此类自我验证框架的价值会持续放大。

Latent Space / AINews

Meta 显式记忆 Agent：对抗长时任务中的行为状态衰减

现状：LLM Agent 在执行长时间、多步骤任务时，越到后期越容易「忘记」早期设定的目标或约束，称为「行为状态衰减」。

问题：上下文窗口虽然可以很长，但注意力分布随长度增加而退化，导致 agent 在任务后期偏离初始指令。

解决方案：引入显式的外部记忆模块（External Memory Agent），将关键目标、约束和中间状态写入结构化记忆，让 agent 在每步决策前先查阅记忆，而非依赖原始上下文。

价值：在长时推理任务上显著减少行为漂移，特别适用于多轮、跨工具调用的 agentic 工作流。

未来方向：记忆的写入策略（什么时候写、写什么）是下一个优化点，当前仍依赖人工规则。

Latent Space / AINews

MuScriptor（Kyutai + Mirelo）：从全混音中多乐器 audio-to-MIDI 开源模型

现状：传统 audio-to-MIDI 转录工具通常要求先分轨（即把鼓、贝斯、吉他分开），才能准确识别每个乐器的音符。

问题：现实中的录音大多是混音成品，分轨步骤引入误差且耗费时间。

解决方案：Kyutai 实验室和音乐科技公司 Mirelo 联合发布 MuScriptor，直接处理全混音音频，同时转录多个乐器的 MIDI 数据，无需前置分轨，模型完全开源。

价值：音乐制作者可以直接把现有录音转为可编辑的乐谱格式，大幅降低采样重建和 cover 制作的门槛。

未来方向：开源策略使社区可以在此基础上构建更专业的编曲工具和训练数据管道。

Latent Space / AINews

Sakana Picbreeder 风格 VLM Agent：多样性提升开放式创造力但仍落后人类

现状：开放式创造力（Open-ended Creativity）——即持续生成真正新颖、未曾预设方向的内容——是 AI 最难逾越的瓶颈之一。

问题：单一 VLM（视觉语言模型）在「探索」阶段快速收敛到已有模式，无法保持人类创作中那种真正的随机漫步。

解决方案：Sakana AI 借鉴 Picbreeder（一种协作式进化图像生成平台）的思路，用多个风格迥异的 VLM Agent 并行探索，互相参考但不合并，保持群体多样性。

价值：多样性 Agent 群体比单 Agent 在创意发散指标上有明显提升，但整体仍落后于人类的开放式探索能力。

未来方向：Agent 间如何选择性地「相互感染」而不过早收敛，是下一个设计挑战。

Latent Space / AINews

Chunked Prefill（Cohere + vLLM）：低批次大幅提速，高批次性能有损

现状：大语言模型处理长输入（Prefill 阶段，即处理提示词）时内存带宽是主要瓶颈，特别是并发请求量少的场景。

问题：Prefill 和 Decode（逐 token 生成）在同一批次里争抢计算资源，导致吞吐量和延迟之间难以兼顾。

解决方案：Chunked Prefill 将长提示词切成小块分批处理，与 Decode 交错执行。Cohere 和 vLLM 团队发布了新的性能数据。

价值：在低并发（小批次）场景下吞吐量大幅提升；但在高并发（大批次）场景下反而有所下降，揭示了这一优化的适用边界。

未来方向：动态批次大小调度是解决高低并发兼顾问题的主要研究方向。
