Elon Musk 庭审证词：xAI 曾用 OpenAI 模型训练 Grok

Musk 在作证时确认 xAI 使用了蒸馏技术（distillation，即用某一模型的输出结果来训练另一个模型），在 OpenAI 模型的输出上训练了 Grok。这是硅谷 AI 圈长期存在的"互相蒸馏"做法首次被公开庭审证词证实——此前这类行为只存在于业界传言和推测中，没有当事方公开承认过。

Anthropic、Meta、xAI 相互蒸馏这件事，大概所有人都在做，只是第一次有人在法庭上说出来。

AI 方向观点

swyx：2026 年的主题是 coding agents 突破边界，进入通用计算

swyx 在 AINews 里明确点出今年的年度叙事：coding agents 不再只待在 IDE（代码编辑器）里帮你写代码，它们正在突破边界——操控浏览器、接入 SaaS 工具、执行跨系统任务、变成通用计算机代理。他把这个趋势命名为"breaking containment"（突破围栏），指 Agent 从原来被限制的单一场景里溢出，开始跑到更广阔的地方。

这个框架解释了为什么 OpenAI 今天把 Codex 扩展到 Office 和 Google Workspace，解释了为什么 Cursor 发布 SDK 让开发者把它的 runtime 嵌进任何产品，也解释了为什么 Claude 开始接入 Blender、Ableton 和 Adobe Creative Cloud。它们都在同一个方向上——把 coding agent 的能力边界从"代码"扩展到"所有可以用计算机完成的事"。2026 年的 AI 产品竞赛，本质上是一场"谁能让 Agent 跑到更多地方"的版图争夺。

Aaron Levie（Box CEO）：Agent 会把软件使用量乘以 100 倍，商业模式必须重建

Levie 对 AI Agent 时代的软件商业模式做了一次系统性分析。他的核心论点是：Agent 调用软件的频率将远超人类——不是快一点，而是快几个数量级。这意味着现有的"座位制"（per-seat，每个付费用户对应一个账号）定价模式会断裂。替代路径是三层架构：座位费（人类用户）+ 消耗费（按 Agent 使用量计费）+ 无头 API（headless，即没有用户界面、完全由代码和 API 驱动的软件架构），最终演变成一个对 Agent 开放的底层平台。Box 自己的战略正是这个方向：Enterprise Advanced 座位收费，同时开放 API 消耗计价。

这个分析的价值在于它给了一个清晰的方向感：任何现在靠"每人一个账号"赚钱的 SaaS，都需要在两到三年内解决 Agent 的定价问题，否则会面临大量使用但无法货币化的尴尬局面。软件的定价单位，正在从"人"切换到"动作"。

GPT-5.5 首次通过英国 AISI 多步骤网络攻击仿真，Anthropic 的防御 AI 领先优势收窄

英国 AI 安全研究所（UK AISI）报告 GPT-5.5 完成了其多步骤网络攻击端对端仿真测试（cybersecurity evaluation，评估模型能否独立完成一整条复杂攻击链），成为第二个完成这项测试的模型。GPT-5.5 平均通过率 71.4%，Claude Mythos Preview 为 68.6%——差距很小。此前的共识是 Anthropic 在防御/进攻 AI 能力测试上有明显领先，这次结果修正了这个判断。值得注意的是，性能在 1 亿 token 推理预算内仍在提升，没有明显饱和迹象。

这件事的深层含义：能够完成高复杂度多步骤网络攻击仿真的模型，已经不止一家。防御侧的 AI 安全团队需要用两个竞争性模型来测试，而不是只盯着一家的进展。进攻能力评测的竞争，比产品竞争更先到达"多极"格局。

AI 进展

AutoResearchBench：科学文献检索 Agent 基准，最强模型准确率不到 10%

现状：AI Agent 在通用网页浏览基准上已经表现出色，但学术文献检索是一个完全不同的难度层次，要求对科学概念的深度理解和细粒度的文献信息利用。

问题：现有基准无法有效区分 Agent 的科学文献检索能力，缺乏既考查"深挖"又考查"广搜"的设计。

解决方案：AutoResearchBench 设计了两类任务。"深度检索"（Deep Research）：给定一个研究问题，通过多步追问找到特定目标论文；"广度检索"（Wide Research）：给定条件，全面收集所有符合条件的论文集合。两类任务都要求对科学概念真正理解，而不是靠关键词匹配。即使是最强的 LLM，Deep Research 准确率仅 9.39%，Wide Research IoU（衡量答案重叠度的指标）仅 9.31%；许多强模型得分低于 5%。

价值：这个基准的低得分直接说明：现有 Agent 还没有能力独立做深度学术调研，"让 AI 帮你综述文献"目前仍然需要大量人工干预。

未来方向：如何让 Agent 理解科学概念语境、进行多跳推理而不只是检索关键词，是下一步的核心挑战。

arXiv 2604.25256

GigaWorld-Policy：动作中心的世界-动作模型，比基线快 9 倍，RoboTwin 2.0 提升 95%

现状：机器人策略学习中，世界模型（World Model，让机器人预测"如果我这样动会发生什么"的内部模型）是提升机器人泛化能力的关键，但现有方法同时预测未来视频和动作，导致推理延迟很高，且视觉质量拖累动作精度。

问题：视觉预测和动作预测被耦合在一起，互相干扰；高质量视频生成带来巨大推理开销。

解决方案：GigaWorld-Policy 把两者解耦：先由动作条件生成未来视频帧，再用视频监督改进动作预测；一个因果设计让未来视频 token 不影响动作 token，推理时可跳过视频生成。结果：比上一代基准 Motus 快 9 倍，同时在 RoboTwin 2.0 机器人任务基准上比 pi-0.5 提升 95%。

价值：更快的推理意味着更低的部署成本，对从研究到实际机器人硬件的落地路径有直接意义。

未来方向：在更多真实环境（非仿真）下的泛化验证，以及视频监督对动作学习的上限测试。

arXiv 2603.17240 · HuggingFace

Qwen3.6-27B：Apache 2.0 开源多模态模型，单张 H100 可运行，超越 397B MoE

现状：开源模型领域长期存在"更大参数量才能更强"的预设，小于 30B 参数的模型在 coding agent 任务上与大模型差距明显。

问题：如何在 27B 参数内做出可以与 397B 混合专家（MoE，一种让不同参数块专注不同任务的模型架构）模型竞争的编程 Agent 能力，同时保持可以在单张 GPU 上运行的部署友好性。

解决方案：Qwen3.6-27B 原生多模态（支持文字、图片、视频输入），引入 Thinking Preservation 机制（保留推理过程的关键中间步骤）和门控 DeltaNet 线性注意力混合架构，在 SWE-bench Verified（代码修复基准）和 SkillsBench（技能基准）上超越之前的 Qwen3.5-397B-A17B，BF16 精度权重在单张 H100 上可运行，支持 SGLang/vLLM/Transformers，Apache 2.0 协议。

价值：以 1/14 的参数量超越更大模型，且部署成本大幅降低，是目前 150B 以下开源模型的新基准线。

未来方向：长上下文（目前为 262K context window）的稳定性，以及视频输入的 agent 任务表现。

HuggingFace · GitHub

Tuna-2（Meta）：像素嵌入打败视觉编码器，多模态理解与生成无需预训练 Vision Encoder

现状：几乎所有多模态大模型都依赖预训练视觉编码器（Vision Encoder，如 CLIP，把图片压缩成向量的专用模块）来处理图像输入，这被认为是保证图像理解质量的必要组件。

问题：依赖视觉编码器增加了架构复杂度，同时编码器的特征空间可能与语言模型的表征空间不完全对齐，成为细粒度视觉感知的瓶颈。

解决方案：Tuna-2（来自 Meta/Facebook Research）完全抛弃视觉编码器，直接用简单的 patch embedding（把图像分割成小块并直接嵌入，不经过专用编码器）处理原始像素，端对端学习视觉表征。实验表明 Tuna-2 在多模态理解基准上达到 SOTA，且在细粒度视觉感知任务上比基于编码器的方案更强；高质量图像生成能力也得以保留。

价值：证明了视觉编码器不是多模态模型的必要组件，为更简洁的统一架构（理解+生成同一个模型）打开了空间。

未来方向：更大规模预训练验证，以及视频输入的 patch embedding 效率优化。

arXiv 2604.24763 · HuggingFace

NS-Mem：神经符号长期记忆框架，多模态 Agent 推理准确率提升 4.35%，约束推理 +12.5%

现状：多模态 Agent 在需要跨时间步骤的推理任务上表现受限，部分原因是纯神经网络记忆（召回快但不精确）和纯符号记忆（精确但刚性）各有短板，组合使用缺乏统一框架。

问题：复杂推理任务（特别是涉及逻辑约束的多跳查询）中，纯神经检索往往召回错误信息，而符号系统的规则维护成本高，两者难以协调。

解决方案：NS-Mem（Neuro-Symbolic Memory，神经符号记忆）在多模态 Agent 的记忆层中桥接直觉性神经检索和确定性符号推理。在多模态推理基准上，平均准确率提升 4.35%；在约束性推理查询（需要精确逻辑匹配的问题）上提升最高达 12.5%。

价值：对需要处理长期记忆（如医疗助手、法律分析 Agent）的场景，神经符号混合记忆是比纯向量检索更可靠的方向。

未来方向：在更大规模 Agent 系统中的计算效率，以及符号规则的自动学习而非手工设计。
