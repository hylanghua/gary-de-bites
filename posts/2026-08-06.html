Google AI 四大核心研究领袖同日出走，Discovery Loop 瞄准自动化科研

Jeff Dean（27 年老将、Google 基础设施之父）、Sanjay Ghemawat（MapReduce/BigTable 共同设计者）、Oriol Vinyals（AlphaStar 负责人）、Quoc Le（Transformer 早期贡献者）在同一天宣布离开 DeepMind，共同创立 Discovery Loop——一家以自动化机器学习研究为目标的公益性公司（Public Benefit Corp）。与此同时，Demis Hassabis 卸任 CEO，转为 Google DeepMind 主席和 Alphabet 首席科学家，兼续领导 Isomorphic Labs；DeepMind CTO Koray Kavukcuoglu 升任 SVP 接管日常运营。Google 已作为创始投资人加入 Discovery Loop，Radical Ventures 与 Khosla Ventures 领投种子轮，Lightspeed、Kleiner Perkins、Doerr Capital 跟投；消息公布后 Alphabet 股票跌约 5%。 这是 AI 史上人才密度最高的单日集体出走之一，也是继 John Jumper 转投 Anthropic、Noam Shazeer 加入 OpenAI 之后，DeepMind 遭受的最大规模人才松动。

Meta 发布 Muse Code：终端编程 Agent，贡献者定价直攻 Claude Code

Meta 推出 Muse Code（beta），一款纯终端编程 Agent（macOS/Linux，无独立 App），底层是 Muse Spark 1.2 模型——在代码生成、复杂调试和大型代码库理解上有显著改进。关键创新是持久后台 Agent（persistent background agents）和本地事件日志（local event log），让长任务可随时恢复，不因网络中断丢失进度。定价上，常规 API 为 $1.25/M 输入、$4.25/M 输出；另有"贡献者定价"$0.30/M——用户允许 Meta 用自己的代码训练未来模型作为交换条件。AINews 特别点出这一 harness（承载 Agent 运行的框架）设计对整个编程 Agent 生态的参考价值。

Bending Spoons 以 12.85 亿美元收购 Airtable，峰值估值缩水近 90%

意大利软件公司 Bending Spoons（今年 7 月刚上市）以全现金交易接盘 Airtable，企业价值 12.85 亿美元，而 Airtable 在 2021 年 AI 泡沫顶峰时估值曾达 110 亿美元。值得注意的是，Airtable 的 AI 业务 Hyperagent 已提前剥离，不在此次收购范围之内——这意味着 Bending Spoons 买走的是一家年 ARR（年经常性收入）约 4.8 亿美元、增速仍超 20% 的传统无代码数据库产品。Obsidian 随即推出工具，允许用户将 Airtable 内容一键导出为 Markdown。

AI 方向观点

swyx（Latent Space 主理人）：Discovery Loop 为何不能在 Google 内部做？

AINews 主编 swyx 对 GDM 人才出走的判断不是感伤，而是追问结构原因。他指出：之前 John Jumper 走是因为 Anthropic 势头；Noam Shazeer 走是因为 reasoning model 的先发优势；但 Jeff Dean、Sanjay、Oriol、Quoc 四人同日出走，再加上此前的 David Silver、Denny Zhou，Google 已经是一个更大的系统性问题。他引用 GDM 出产"1000+ 作者"超大联合论文的文化，对比 Discovery Loop 四人团队写出的精炼宣言，暗示自动化科研（autoresearch）这条路在大公司的协调成本下已无法推进，必须以创业形式另起炉灶。Google 仍有顶级模型、算力和人类史上最大训练数据集——但执行层的信念是否还在，是接下来的关键问题。

Peter Yang：/human-review 技能——把 AI 输出的人工审核变成浏览器内联批注

AI 进展

Qwen-UI-Agent：跨平台 GUI Agent，移动端超越 Opus 4.8 和 GPT-5.6 Sol

现状：GUI Agent（图形界面操作 Agent）面临的最大挑战是"真实设备泛化"——在实验室 benchmark 表现好，但在真实手机/电脑上失效。

解决方案：Qwen-UI-Agent 构建了覆盖移动端、PC、网页、DeepSearch 的统一 Agent 框架，结合大规模真实设备运行时数据进行训练，并用多任务策略防止能力遗忘。

价值：在 MobileWorld 达 82.1%、MobileWorld-Real 达 92.2%、OSWorld-Verified 达 79.5%、WebArena 达 73.6%，全面超越 Opus 4.8 和 GPT-5.6 Sol。

未来方向：GUI Agent 正从"演示可用"走向"真实设备可用"，多模态感知+跨平台统一策略是主线。

HF · 2607.28227 · arXiv

Metis：首个 Memory Foundation Model，原生记忆状态嵌入模型骨干

现状：现有 LLM 的"记忆"依赖外部检索（RAG，即检索增强生成）或扩展上下文窗口，两者都是架构层面的补丁，而非模型原生能力。

解决方案：Metis 在 Transformer 骨干中引入"原生记忆状态"（native memory state），历史信息通过记忆注意力（memory attention）压缩进模型计算流，推理时无需外部调用，更新只需前向计算，无梯度回传。

价值：将长时序信息处理内化为模型本体能力，理论上可打破上下文窗口长度限制，且更新无需重新训练。

未来方向：记忆基础模型有望成为 Agent 长任务记忆的新范式，取代检索索引+外部存储的拼接方案。

HF · 2607.26760 · arXiv

AskChem：以"主张"为检索单元，构建化学文献合成基础设施

现状：科研文献检索系统以"文档排名"为核心，返回的是论文列表，研究者仍需自行从文章中提取具体结论，耗时且难以跨文章综合。

解决方案：AskChem 把检索单元从"论文"改为"原子主张"（atomic claim）——每条主张携带来源 DOI 和原文引用，构成知识图谱供检索和推理；已索引 147K 篇论文、240 万条主张，提供 REST/SDK/MCP 接口供 AI Agent 调用。

价值：化学研究者可以直接问"哪些研究支持 X 和 Y 的相关性"，而非检索关键词再手动阅读，大幅缩短文献综合环节。

未来方向："主张粒度检索"可推广至其他科学领域，是自动化科研（autoresearch）知识层的关键基础设施。

HF · 2607.28618 · arXiv

VideoCoCo：代码作为 CoT，先仿真后渲染，让视频生成遵守物理定律

问题：文本到视频模型视觉质量高，但生成的物体运动常违反物理：弹跳轨迹错误、碰撞无因果、液体乱流。原因是时序动态从压缩文字提示中隐式推断，太难。

解决方案：VideoCoCo 用 Agent 先写 Blender 仿真代码，在沙箱中渲染出"中性白模视频"（正确的运动/物理/因果，无材质），再以扩散模型将白模重新渲染成真实感视频，代码即推理链（Code-as-CoT）。

价值：物理一致性与视觉质量解耦，分两步各自优化；生成过程可检验（白模可以被人工或自动审查）。

未来方向：仿真引擎驱动的视频生成为机器人训练数据合成提供了新路径。

HF · 2607.27380 · arXiv

Prime Agent：自改进 RLM 框架，以 Opus 5 在 ARC-AGI-3 达 95.5%

现状：当前编程 Agent 框架（harness）大多是固定脚手架，不能根据任务失败自行调整工具调用逻辑。

解决方案：Prime Intellect 推出 Prime Agent，核心是可递归语言模型（RLM，Recursive Language Model）思路：子 Agent 以函数调用形式嵌套，harness 状态（Agent 运行环境的配置）可在任务执行中自修改；同时支持多 Agent 消息传递和上下文作为变量，让 Agent 能"自己改进自己的运行框架"。

价值：以 Opus 5 为底模，在 ARC-AGI-3（考察抽象推理的基准测试，人类专家基线约 85%）上达 95.5%，创下该基准最高分；MIT 许可证开源。注：该分数尚未经过 ARC Prize 官方认证。

未来方向：自改进 harness 模式若成立，将让 Agent 基础设施本身成为被优化的对象，而非仅有模型能力在进步。
