AI 方向观点

Zach Lloyd：软件工程师的下一个身份是"工厂工程师"

Warp CEO Zach Lloyd 在 AI Engineer World's Fair（AIEWF）演讲中提出：AI coding 正将软件工程从"手工艺"推向"工厂生产"。未来工程师不再逐行写代码，而是管理 AI 流水线的工厂工程师（factory engineer）——设计流程、设置质检节点、提升产线吞吐量。这不是职业消亡，而是职责迁移：从生产者变成生产线设计者。

Latent Space / AIEWF

swyx：loopcraft 与 AI Engineer 时代的核心技能

Latent Space 主理人 swyx 在 AIEWF 主旨演讲中提出"loopcraft"概念：AI 工程师的核心技能已从调用 API 演进为设计和调试 agent loop。他认为 2026 年的 AI 工程师必须理解 loop 的健康状态（observability）、失效模式（failure modes），以及如何在 loop 中嵌入人类判断节点（human-in-the-loop checkpoints）。

产品与商业

Every.to：Codex in Practice — 编辑团队六周实验报告

Every.to 发布 Codex in Practice 报告，记录编辑团队将 OpenAI Codex（现 o3 API）用作团队工作空间六周的实验：任务分配、知识文档共享、跨职能代码联调。核心结论：Codex 在异步协作（async collaboration）中优于实时 AI 助手，尤其适合"分头做任务、合并检验"的场景；但"共识建立"与"方向决策"仍是人类强项。

Every.to

Aaron Levie：企业 AI 安全共同框架

Box CEO Aaron Levie 发布其团队整理的企业 AI 安全共同框架，涵盖四个维度：数据驻留（data residency）、访问控制（RBAC with AI scope）、审计日志（audit trail with model attribution）、模型切换（vendor-agnostic switching）。框架面向同时接入多家 AI 供应商的企业，旨在降低供应商锁定与合规风险，已开放 GitHub 共享。

Tim Ferriss 播客新集邀请整合医学先驱 Dr. Andrew Weil 与植物人类学家 Wade Davis 同台，围绕古柯叶展开三小时对话。从安第斯原住民的传统使用，到西方世界对"危险植物"的系统性妖魔化，再到现代医学对植物智慧的重新审视——三人共同指向一个结论：焦虑文明的解药或许藏在被遗忘的植物知识里，而非下一种合成分子。值得搭配 Michael Pollan 的《植物的欲望》一起读。

AI 进展

VibeThinker-3B：用直接推理蒸馏让小模型获得强推理能力

提出 Direct Reasoning Distillation（DRD）框架，让 3B 小模型从大模型推理链中蒸馏"思考能力"而非最终答案。在 AIME 2026 上达 94.3%，超越多个 7B 竞品。结论：推理能力是可迁移的高层结构，不依赖参数量，关键在于蒸馏的粒度与对齐策略。

arXiv 2606.16140

Unlimited OCR Works：任意文档、任意版式、任意语言

百度提出 Rotary Sliding Window Attention（R-SWA）机制，解决长文档 OCR 中版式混乱与跨语言识别难题。在公开 OCR 基准上取得 SOTA，混合版式（表格 + 公式 + 图片混排）场景领先尤为显著。对需要大规模文档数字化的企业（法律、金融、档案）有直接落地价值。

arXiv 2606.23050

MinerU2.5：开源精准文档内容提取方案

上海 AI Lab 发布 MinerU2.5，1.2B 参数文档理解 VLM，专攻 PDF 与扫描件的结构化提取（标题层级、表格、代码块、数学公式）。在 OmniDocBench 上以小参数量超越多个商用 API，且完全开源。对 RAG pipeline 的文档预处理环节有直接替代价值。

arXiv 2509.22186

GeneBench-Pro：评估 AI 在专业生物任务上的能力

OpenAI 联合生命科学机构发布 GeneBench-Pro 基准，涵盖基因编辑设计、蛋白功能预测、文献综合三类专业任务。GPT-5.6 Sol 在最难子集得 28.7%，超越人类专家基线 19%；但在需要湿实验验证的任务上仍不可靠——AI 知道答案，却无法感知实验约束。

bioRxiv 2026.06.29

探索 Agentic Memory 系统的跨场景泛化能力

系统研究 agent memory 在不同任务场景间的迁移效果（旅行规划 → 代码调试 → 知识检索）。发现情景记忆（episodic memory）比语义记忆跨场景迁移更稳定；memory 压缩策略对泛化性的影响超过 memory 容量本身。对构建长期运行 agent 的工程师有直接参考价值。
