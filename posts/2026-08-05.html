Shai-Hulud npm 蠕虫攻陷 868 个包，月下载量逾 20 亿

攻击从劫持 keyv 维护者 GitHub 账号开始，随后向受控包注入恶意 preinstall hook：在安装时悄然清扫 npm 凭据、GitHub CLI 令牌、AWS 环境变量、Kubernetes 配置、Vault token 及加密货币钱包，并自动传播至受害者名下所有包。安全研究员将其命名为"沙虫"（Shai-Hulud），已知月下载量合计超 20 亿次，实际暴露面尚待统计。npm 已下架受感染版本，但历史版本仍可能在 CI/CD 流水线中存在。

AI 进展

CompanionBench：首个理论锚定的 AI 陪伴能力基准

从 25 个心理学与咨询理论中提炼出 10 项核心能力，构建双语（中英）评测框架，包含分支人格轨迹，旨在系统衡量 AI 陪伴场景的真实表现。既非单纯对话质量测试，也非情感安抚能力评测，而是理论驱动的多维度能力图谱，8 月 3 日提交。

arxiv 2608.02046

ContinualSkillBench：上下文持续技能学习动态基准

5 个领域 × 100 个互联子任务，动态评估模型在上下文中的持续技能学习能力。关键发现：上下文自适应与显式技能维护的提升幅度几乎相同——进步来自上下文适应，而非可复用技能抽象，对 Agent 长任务设计有直接启示。

arxiv 2608.03874

Memory in the Loop：进程内检索作为语言 Agent 的扩展工作记忆

将检索存储嵌入 Agent 进程内，延迟约 100 微秒（比网络调用快三个数量级）。依据延展心智论的等效原则：足够快的外部存储在功能上等同于工作记忆，而非工具调用——这重新定义了 Agent 记忆架构的设计边界。

arxiv 2607.05690

HarnessFix：从失败轨迹到可靠 LLM Agent

提出 HTIR（Harness-aware Trace Intermediate Representation），将执行轨迹与 harness 代码编译为中间表示，自动诊断并修复 harness 缺陷。在 4 个基准上验证，将"Agent 失败是模型问题"的默认归因转向"harness 设计问题"，对生产 Agent 调试有实用价值。

arxiv 2606.06324

Harness 设计系统性扭曲 Agent 信念——Belief Divergence 测量

研究发现 harness 设计不只影响任务完成率，更会系统性地偏移模型在多步任务中对当前状态的"信念"——即模型认为正在发生的事与实际不符。量化这种信念偏离是构建可靠生产 Agent 的必要前提。
