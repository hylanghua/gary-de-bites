OpenAI-微软重签协议：Azure 独占终止，AGI 条款正式消失

微软与 OpenAI 签署了新版合作协议，核心变化有三条：Azure 不再是 OpenAI 模型的独占云平台，OpenAI 可以将产品部署到 Google Cloud 和 AWS 等任何云上；微软对 OpenAI 技术的授权延续至 2032 年但改为非独占；原本规定「一旦 OpenAI 宣布达成 AGI（通用人工智能），微软商业授权随即失效」的条款被彻底删除，改为 OpenAI 对微软的营收分成「独立于 OpenAI 的技术进展」延续到 2030 年。Simon Willison 梳理了这一条款的演变历史：AGI 的定义从最初的模糊表述，到去年改为「独立专家委员会评定」，再到如今完全脱钩——这意味着无论 OpenAI 宣布实现了什么，都不会再触发任何合同条款。

对于整个 AI 行业，这次改动是一个信号：算力基础设施的竞争已经进入新阶段，AWS 的 Andy Jassy 随即确认 OpenAI 模型将在未来几周内上线 Bedrock（Amazon 的托管 AI 服务），OpenAI 获得了实质性的定价筹码。

OpenAI 秘密研发 AI 手机：2028 年量产，以 Agent 替代 App

OpenAI 正在与 Qualcomm 和 MediaTek 合作开发定制手机芯片，Luxshare（富智康，负责 iPhone 代工的同一家公司）可能承接设计与组装。量产时间预期在 2028 年，规格和供应商确认将在 2026 年底到 2027 年一季度完成。这款手机的核心差异点不是硬件参数，而是交互逻辑：不再以 App 为基本单位，改以 AI Agent 端到端执行任务，较重的计算推回 OpenAI 云端。如果方向成立，App 生态和操作系统的竞争格局都将面临压力。

Anthropic 二级市场估值逼近 1 万亿美元

Anthropic 在二级市场（secondary market，即已发行股份在现有投资者之间的转让市场）的交易估值已接近 1 万亿美元，与此同时 OpenAI 的同类交易定价约在 8000 亿至 9000 亿美元之间。三个月前 Anthropic 刚以 3800 亿美元估值完成一轮融资，这意味着短时间内市场情绪驱动的溢价已超过两倍。推动估值的实质基础是 Claude Code 的快速增长和企业端收入，但 AI Valley 的分析指出，部分上涨带有强烈的情绪成分：股份稀缺，买家争夺访问资格本身已经成了资产。

AI 方向观点

swyx（Latent Space）：GPT-Image-2 是 AGI 路径上的「多模态闭环」

swyx 在本期 AINews 里的核心论点是：GPT-Image-2 的意义不止于图片生成，而在于它是 AGI 的「G（General）」维度不可绕开的一步。他的逻辑是：如果 AI 只能处理文字和代码，那「G」只覆盖了人类信息的一部分——真正的 General 需要能生成和理解图像、图表、信息可视化乃至透明图层。GPT-Image-2 和 Codex 的组合已经形成了一个完整的「写代码 + 生成视觉资产」的闭环（closed loop），而「能否闭环」正是他判断一个模型是否在走向 AGI 的核心标准。

他同时观察到一个竞争格局：当所有实验室都在冲向编码和企业 AI，图像生成反倒是被忽视的战场。Claude Design 曾是「当前焦点」，但 GPT-Image-2 出来之后，它在讨论中几乎从对话里消失了——「能闭环者赢」这个规律在每一轮工具替代里都成立。

swyx 说的不是「图片生成有用」，而是「多模态生成能力决定了 AGI 路径是否完整」，这是一个需要记住的框架。

Latent Space / AINews · X @swyx

Zara Zhang（Builder）：成熟用户已进化到「一个 orchestrator agent + 按需派生子 Agent」

Zara 在 X 上观察到一个正在出现的使用范式转变：成熟的 AI 用户不再每天切换多个 AI 工具，而是只和一个「编排器 Agent」（orchestrator agent，即负责拆分任务并分配给其他 Agent 的主控 Agent）对话，由它根据需要动态派生子 Agent 来执行具体任务。这与当前多数 AI 产品的设计逻辑相反——现在的产品还在争夺作为用户直接交互的入口，但领先用户已经在实践「一级意图 + 多层执行」的结构。

这个观察对产品设计有直接含义：未来的竞争可能不是「谁是最好的单个 AI 工具」，而是「谁能成为最好的 orchestrator」——就像操作系统不是最好的软件，但是所有软件运行的平台。

Zara 描述的不是一个功能，是一种用户心智模型的迁移——从「工具切换」到「意图下达」。

Matt Turck（FirstMark Capital）：AI 正在两个平行世界里运行

Matt Turck 在 X 上点出了一个他在市场上观察到的认知断层：「硅谷：AI 在自我加速，正在改变一切；全球 2000 强企业：我两年前花了一大笔钱买了你们的 AI chat，生产力零提升。」这两句话描述的不是两类公司对 AI 的不同态度，而是 AI 落地的结构性障碍——同一波技术，在不同组织的落地速度和质量差距正在扩大。

这个断层本质上是「AI 能做什么」和「企业能消化什么」之间的鸿沟，而它在大模型能力跃升的背景下反而在加深，而不是收窄。对于 B2B AI 工具的 PM 来说，这是一个直接影响 GTM 策略的信号。

AI 的两个世界之间，最大的变量不是模型能力，而是组织的消化速度。

Ben Gilbert（Ben's Bites）：不要把好东西变成机器

Ben 从旧金山回来，写了这期 Newsletter 里少见的个人反思。旧金山的空气里充满「更快、更大、更成功」的能量，他理解但不完全认同：「我对自己的野心版本看起来有点不一样。」他在 SF 读到了一篇 Lenny 的人物档案，触动他的部分是「深度在意这份工作，但不让它吞噬其他一切」——就是这种平衡。

他对 Agent 时代的框架是：Devtools 今天是为开发者设计的，明天 Agent 就会直接拿起这些工具，组合、运行命令、改文件、接通系统。人类的工作是「懂得足够多的工作形状，好好指挥」。他不想要规模化的计划，他回来时的想法是：「我想继续为这一批 builder 构建，这批人好奇、日益技术化、用 AI 变得更有能力。」

Ben 把「品味」和「不过度增长」当作 Builder 的竞争优势，而不是失败借口——这在 SF 的叙事里是罕见的声音。

Lenny Rachitsky：AI 的 Couch-to-5K ——把 AI 学习拆到每天不足 10 分钟

Lenny 邀请行为改变专家 Hilary Gridley（曾在 WHOOP、Dropbox、Big Health 等公司研究用户习惯改变）共同发布了一个免费 AI 学习项目。核心前提：当人们说「太忙了」，背后往往不是时间问题，而是一个更深的障碍，通常是惰性、不确定性或对失败的焦虑。破解方式不是等待合适时机，而是把第一步拆到极小，然后迈出去。这套逻辑来自研究：拖延的本质是等待外部条件改变，而心理学家 Tim Pychyl 的研究表明「一旦开始，通常就能继续」。

这个项目把 AI 学习拆成每天不到 10 分钟、循序渐进的日常练习，起点是会问问题，终点是用 Claude Code 自己构建工具。他们用的行为改变原理和「跑步 Couch-to-5K 计划」相同：小赢积累信心，信心产生动力，动力带来下一步。

Lenny 这期把 AI 普及问题转化成了一个行为设计问题，而不是技术教育问题，角度切换本身比内容更有价值。

Amjad Masad（Replit CEO）：20 个 builder 8 周创收冲刺，垂直集成才是 Agent 护城河

Masad 在 X 上宣布 Replit 正在推进一个 20 个 builder、8 周的创收冲刺计划（revenue sprint）。Replit 的核心主张是：把基础设施、编辑器、运行时和部署全部封装在同一平台里，为 Agent 提供优于分散工具链的「生产隔离」（production isolation，即 Agent 运行时与宿主系统之间的边界，防止 Agent 代码意外破坏关键数据）。他认为这是面对编码 Agent 竞争加剧的正确押注方向：不是最快更新单个功能，而是整合整条链。

Replit 的垂直集成赌的是：Agent 时代的平台价值高于单个工具，集成深度才是护城河，不是单点能力。

Tim Ferriss / Dr. Tommy Wood：大脑抗老实用手册——B 族维生素和 Omega-3 必须配合使用

华盛顿大学儿科与神经科学副教授 Tommy Wood 为 Tim Ferriss 博客写了这篇实证型指南。最反直觉的发现之一：B 族维生素（尤其 B12 和叶酸）和 Omega-3 脂肪酸单独使用时减缓脑老化的效果平平，但两者协同使用才能真正发挥作用——两种营养素互为放大器。他同时用 20 年的追踪研究支持了一个不够「高端」的结论：处理速度训练（processing speed training，即提升大脑快速识别和反应的能力，如视觉追踪游戏）的认知益处显著，Super Mario 和 StarCraft 不只是娱乐。

其他值得记住的发现：带状疱疹疫苗（shingles vaccine）在多项研究中持续出现在降低失智症风险的相关因素里，原因尚不完全清楚，但证据足够强到值得行动。空气污染、PFAS（全氟化合物，一类持久性化工污染物）和微塑料对认知功能都有可测量的影响，但「一次性装好过滤器」是最高 ROI（投入产出比）的应对方式，不需要焦虑。

Tommy Wood 给的不是「努力活得健康」的鸡汤，而是从几十年研究里提炼出的、干预成本最低而效果最强的优先项清单。

AI 进展

Agentic World Modeling：三级能力 × 四种法则域（arXiv 2604.22748）

现状：世界模型（world model，即 AI 在内部对环境动态建模以支持预测和决策的能力）研究跨越了机器人控制、视频生成、Web Agent 和科学发现等领域，但缺乏统一分类框架，文献之间难以横向比较。

问题：如何系统评估和规划世界模型的研究方向，目前没有共识的维度和层级定义。

解决方案：本文综合了 400 余篇文献，提出三个能力层次：L1 预测器（学习单步局部转移）、L2 模拟器（组合多步、动作条件化预测）、L3 进化器（当预测失败时自主修正自身模型）；以及四种「法则域」（governing-law regimes）：物理、数字、社会、科学，决定了世界模型需要满足的约束和最常见的失败模式。

价值：横跨 100+ 代表性系统，提供架构指导、开放问题和治理挑战的分析，是目前最全面的 Agentic World Modeling 综述。

未来方向：提出决策导向的评测原则和可复现最小评测包，为从强化学习到具身 AI 的下一步研究指路。

arXiv 2604.22748 · HuggingFace Papers

DFlash：块扩散投机解码，单次前向推理出全部草稿，6 倍无损加速（arXiv 2602.06036）

现状：投机解码（speculative decoding，即用小模型先生成草稿 token，再由大模型验证，通过并行验证提速）是当前主流推理加速方案，但现有方法仍然依赖自回归（autoregressive，即逐一生成）的起草阶段，推理成本随草稿 token 数量线性增长。

问题：自回归起草迫使架构极度精简以控制延迟，反过来限制了草稿质量和接受率，二者难以同时优化。

解决方案：DFlash 用轻量级块扩散模型（block diffusion model）生成草稿——所有 token 在一次前向推理中并行生成，起草成本与 token 数量解耦，利用大模型抽出的上下文特征提升草稿质量。

价值：在多类模型和任务上实现 6 倍以上无损加速，比当前最优方法 EAGLE-3 再快 2.5 倍。对长文本生成和 Agent 工作流中的高频推理场景尤为显著。

未来方向：进一步扩展到 MoE 架构和超长上下文推理，探索扩散起草在多模态场景中的应用。

arXiv 2602.06036 · HuggingFace Papers

SkillClaw：多用户 Agent 技能集体进化，6 轮后性能提升 88%（arXiv 2604.08377）

现状：LLM Agent 依赖可复用的「技能」（skill，即预定义能力模块，如「查日历」「发邮件」）提升效率，但这些技能在部署后基本是静态的，用户发现的优化和失败模式无法自动积累为系统改进。

问题：相似的工具调用模式、失败路径在不同用户间被反复重新发现，系统无法从使用经验中学习，类似每位用户都在从零摸索。

解决方案：SkillClaw 持续汇聚跨用户的 Agent 使用轨迹，由自主 Evolver 识别反复出现的行为模式并更新技能库，改进同步到所有用户，无需用户主动反馈。

价值：在 WildClawBench（真实 Agent 场景评测集）上，经过 6 轮集体进化后性能提升 88%，实现了跨用户知识迁移的系统性积累效应。代码已开源。

未来方向：将机制扩展到多 Agent 协作系统的技能市场（skill marketplace）和跨组织知识共享场景。

arXiv 2604.08377 · HuggingFace Papers

Sakana Conductor：7B RL 编排器协调前沿模型，83.9% LiveCodeBench（arXiv 2512.04388，ICLR 2026）

现状：多 Agent 系统通常由工程师手动设计任务分配和协作拓扑（topology，即 Agent 之间的调用图），灵活性差，无法根据问题动态调整。

问题：静态编排无法适应不同类型问题对子 Agent 能力和协调方式的不同需求，也无法从经验中优化编排策略。

解决方案：Sakana AI 用强化学习（RL）训练了一个 7B 参数的 Conductor 模型，让它学会用自然语言动态决定哪个子 Agent 处理哪个子任务、子 Agent 之间如何共享上下文——不直接解题，只编排。Conductor 还可以把自己作为 Worker 之一，形成递归拓扑。

价值：在 LiveCodeBench 上达到 83.9%，在 GPQA-Diamond（研究生水平多学科问答基准）上达到 87.5%，超过其所编排的任何单一 Worker 模型的表现，验证了「AI 管理 AI」作为测试时算力扩展的新维度。

未来方向：递归拓扑的深层应用，以及在开放域科学研究和工程任务中验证 Conductor 的泛化能力。

arXiv 2512.04388 · Sakana AI

Kronos：金融 K 线专用基础模型，预测排名 IC 超最强 TSFM 93%（arXiv 2508.02739，AAAI 2026）

现状：金融时间序列预测（K 线数据，即股票、期货等资产的开盘、收盘、最高、最低价及成交量序列）历来依赖特征工程加传统机器学习，近年通用时间序列基础模型（TSFM）也被移植进来，但表现一直受限于金融数据的特殊性。

问题：通用 TSFM 的预训练数据来自气温、能耗等物理信号，与金融 K 线的非平稳性、厚尾分布和市场微结构噪声特性差距极大，直接迁移效果不佳。

解决方案：清华大学团队开发的 Kronos 引入专用 tokenizer（标记化器）将价格动态和成交活动模式离散化为 token 序列，在来自 45 个全球交易所超过 120 亿条 K 线记录上进行自回归预训练。与微软 Qlib 的集成提供了开箱即用的 A 股回测管道。

价值：价格序列预测的 RankIC（排名信息系数，衡量预测与真实涨跌排名相关性的指标）比最强通用 TSFM 高 93%，比最优非预训练基线高 87%，波动率预测 MAE 降低 9%，合成 K 线真实度提升 22%。

未来方向：将 Kronos 扩展到衍生品和多资产联合预测，以及探索合成数据在金融 Agent 回测中的应用。
