Every OpenAI 的基础设施：拆解一家 AI 媒体的技术栈

AINews（Latent Space）深度分析 Every OpenAI 作为 AI-native 媒体的运作方式：从 Claude 生成初稿、到编辑介入定稿、再到读者个性化推送，全流程几乎由 AI 驱动。文章指出这套流程的核心不是"AI 写作"，而是"人类判断力在哪个节点介入"的设计问题。

Latent Space / AINews

Agent-to-agent 的调试陷阱

steipete 在实际工程中发现：当多个 agent 串联时，上游 agent 的输出格式错误会被下游 agent 静默接受，最终在意想不到的地方爆发。他提出"在每个 agent 边界做显式断言"的工程原则，比依赖模型自己发现错误要可靠得多。

steipete.me

Anthropic：80% 的 Claude Code 提示来自 agent 而非人类

Anthropic 公布数据：Claude Code 当前 80% 的 prompt 由其他 agent 生成，人类直接输入只占 20%。这一比例意味着 Claude Code 的主要使用模式已经是 agent-in-the-loop，而非 human-in-the-loop，对模型在非监督环境下的鲁棒性提出更高要求。

rauchg：Grok 4.5 与 Kimi K3 的安全边界测试

Guillermo Rauch 在测试 Grok 4.5 和 Kimi K3 时发现两款模型在安全拒绝策略上存在显著差异：Grok 4.5 在部分敏感提示上拒绝率明显偏低，而 Kimi K3 则更接近主流安全标准。他认为开放权重模型的安全对齐是比性能更关键的长期问题。

产品与商业

纯银：豆包"无限对话"体验流的设计逻辑

纯银在小报童分享了他对豆包最新版本"无限对话流"的观察：豆包将单次对话的上下文限制从界面上隐藏掉，用滚动加载代替"新开对话"的操作断点，让用户感知不到记忆边界。他认为这是一种"把技术约束包在产品设计里"的成熟做法，比直接暴露 context window 更有利于留存。

纯银 / 小报童

@thenanyu：好产品不解释自己

Nan Yu 发推：真正好的产品从不需要向用户解释"为什么要这样做"——用户会直接感受到。他以 Kimi K3 的发布页面为例，指出其文档的克制风格和基准数据的呈现方式，比大多数 AI 产品的发布 blog 更有说服力，因为它"让数据说话，不自夸"。

人文与哲学

Aaron Levie：AI 不会消灭工作，只会重写工作的定义

Box CEO Aaron Levie 发文回应近期关于 AI 替代就业的讨论：历史上每一次技术浪潮（蒸汽机、电气化、互联网）都曾被预言为"终结就业"，最终结果是就业总量上升但工作性质彻底改变。他认为当下的 AI 浪潮与此一致，真正消失的是"重复性认知劳动"，诞生的是"理解和指挥 AI 的新型角色"。但他也坦承：这次转型速度比以往任何一次都快，政策和教育体系跟不上是真实风险。

AI 进展

Kimi K3 技术报告：MoE 架构与训练细节

月之暗面随模型发布同步公开技术报告。K3 采用 Mixture-of-Experts 架构，2.8 万亿总参数、每次推理激活约 320 亿，训练数据逾 15 万亿 token。报告重点披露了其强化学习后训练方案和多语言对齐策略，是迄今公开最详尽的大规模 MoE 训练文档之一。

arXiv / Moonshot AI

Molt：多目标长时程任务基准

Molt 提出针对"长时程、多目标"任务的新型评估框架，专注于测量模型在执行跨越数十步骤的复杂任务时的目标追踪能力。实验显示当前顶级模型在任务步骤超过 20 步后，目标遗忘率显著上升，揭示了现有模型在 agent 场景下的核心短板。

arXiv:2607.21653

DataPrep-Bench：数据预处理能力的系统评估

DataPrep-Bench 构建了首个专门评估 LLM 数据清洗与预处理能力的基准，覆盖 12 类常见数据质量问题。结果发现模型在结构化异常检测上表现相对稳定，但在隐式语义错误和跨列关联问题上准确率普遍低于 50%。

arXiv:2607.20465

Skill Self-Play：无需人类标注的技能自动习得

Skill Self-Play 让模型通过自我对弈迭代生成技能描述与对应练习题，实验表明在无任何人类标注数据的情况下，模型在多项技能习得指标上显著优于监督微调基线，为低资源场景下的专项能力提升提供了新思路。

arXiv:2607.22529

SciCodePile：科学代码大规模预训练语料

SciCodePile 收录来自物理、化学、生物、材料等领域的 1800 万段科学代码，是目前规模最大的科学领域代码预训练数据集。初步实验显示在 SciCodePile 上继续预训练后，模型在科学计算任务的正确率提升约 12 个百分点。
