DeepSWE 取代 SWE-Bench Pro 成 Artificial Analysis 编码 Agent 新评测标准；Claude Code + Fable 5 以 77 分领跑

Artificial Analysis 宣布把 SWE-Bench Pro 从其编码 Agent 排行榜（Coding Agent Index）中撤下，替换为 Datacurve 的 DeepSWE。原因直接：SWE-Bench Pro 已可通过访问历史 commit 信息的方式被系统性「刷分」（评测人员事先读过答案的现象），而 DeepSWE 的 113 个任务均从零写起，覆盖 91 个真实开源仓库，不存在答案泄露路径。新排行榜显示：Claude Code + Fable 5 [max] 以 77 进入榜首，Codex + GPT-5.5 [xhigh] 以 76 紧随，Claude Code + Opus 4.8 [max] 以 73 居第三。

这一更换也暴露了一个结构性问题：「编码 Agent 排行榜」越来越是在评测 harness（Agent 运行的脚手架系统）和模型的组合能力，而不只是模型本身。有分析者指出，同一个底层模型在不同 harness 下分数差异可以超过 10 分。对 PM 的启示：评测数字背后的 harness 质量，可能比模型分数更值得关注。基准游戏化导致 SWE-Bench Pro 退场，这不是第一次，也不会是最后一次——评测本身需要持续更新才能维持可信度。

AI 方向观点

Dan Shipper（Every.to CEO）：Fable 的寓意——只有在 Level 7-8 的人，才真正感受到前沿模型的力量

Dan Shipper 在 Every.to 的这篇文章提出了一个逆直觉的观点：Fable 5 对大多数知识工作者来说感觉「差不太多」，不是因为它不强，而是因为大多数人还没找到能释放它能力的使用姿势。他援引了 Every.to 八级 AI 采用框架：大多数人在 Level 3-5（用 AI 生成草稿、改善流程），而真正感受到 Fable 力量的，是 Level 7-8 的人——他们把整个项目委托给 Agent，让 Agent 异步工作，自己只负责审阅结果和学习。Cora 的产品经理 Kieran Klaassen 是他举的例子：以前需要几天的 bug 修复和功能请求，现在几小时内清完。

Shipper 用「园艺」（gardening）而非「提示」（prompting）来描述这种工作方式的本质——你在设计和维护一个生长环境，而不是在下达单次指令。他还点出了一个结构性趋势：Claude Code 最初是开发者工具，现在同样的工作方式已被用于幻灯片、表格、内部研究，扩散到所有知识工作。这意味着「Level 7-8 会是少数人特权」这个判断，可能只在未来 18 个月内成立。前沿模型的价值不均匀分布在使用者之间——你的使用层级，比你的职业更能决定你从 AI 里拿回多少。

AI 进展

DRPO：软正则化替代硬掩码，LLM 强化训练在 trust-region 边界外也有连续梯度修正

现状：用强化学习（RL，reinforcement learning，通过试错和奖励信号优化模型行为的训练方法）调优大语言模型时，标准方法依赖「信任域（trust region）」约束——当某次更新超出安全边界，梯度被硬掩码直接截断，相当于直接告诉优化器「这步不算」。

问题：硬截断导致边界处梯度不连续：明明越界了一点点的更新方向可能是有用的，但被一刀砍掉；大规模 RLHF（用人类反馈做强化学习，Fable / GPT 等模型对齐的核心训练技术）中这种崩溃尤其常见。

解决方案：DRPO（Divergence Regularized Policy Optimization）把硬掩码换成平滑的二次正则化项：在边界内正常更新，接近边界时引入连续惩罚权重，越界越大，但始终可微分——梯度不再消失，而是被压制和修正。

价值：训练曲线更稳定，大规模 RLHF 里减少了「突然崩溃再恢复」的震荡；对从事 LLM 微调（fine-tuning）和对齐训练的工程师有直接实用价值。

未来方向：软正则化框架有潜力成为 PPO / GRPO 等算法中硬约束部分的标准替代，向下一代 LLM 对齐训练管线扩散。

Robust-U1（ICML 2026）：多模态大模型可通过强化学习主动恢复被污染的视觉内容，不再只靠文字推理弥补图像缺陷

现状：多模态大语言模型（MLLM，multimodal LLM，同时理解图像和文字的模型）在处理噪声、压缩、遮挡等被污染图像时表现不稳定；现有方法要么做特征对齐（黑盒，无可解释性），要么靠文字推理弥补，但文字无法恢复丢失的像素级信息。

解决方案：Robust-U1 给 MLLM 装上「视觉自修复」能力，分三阶段训练：① 用标准有监督微调（SFT）做初始视觉重建；② 用双重奖励的强化学习（RL）精调——像素级 SSIM（结构相似度，衡量图像质量的指标）和语义级 CLIP 相似度（用 CLIP 模型衡量图像含义是否保留）同时作为奖励信号；③ 联合推理，同时考虑受损输入和已恢复图像。

价值：在真实图像污染基准上达到 SOTA，且保持在对抗性污染下的鲁棒性；对处理低质量用户上传图像的产品（医疗影像、文档扫描、用户照片理解）有直接参考价值。

未来方向：视觉自修复作为 MLLM 的标准能力层将向下游应用扩散，降低对输入图像质量的前置要求。

arXiv 2606.08063 · HuggingFace Papers

DuplexOmni：实时全双工多模态交互——听、看、思、说四路并行，思考不再阻塞响应

现状：现有语音/多模态 AI 系统大多是半双工（half-duplex）：说话时不能听，听完之后才开始想，想完才开始说——这和人类对话节奏差距明显，打断、附和、实时反应都不可能。

解决方案：DuplexOmni 把模型分成两层异步并行的组件：交互层（interaction layer）是端到端实时模型，持续处理流式音视频输入，同步生成语音响应；思考层（thinking layer）是可插拔模块，专门负责复杂推理和工具调用（调用外部 API 或搜索引擎等）。两层异步运行——思考层在后台运转时，交互层仍然保持对话的连贯性和即时响应。

价值：彻底解除「思考」和「响应」之间的顺序依赖；在视频会议 AI、客服、实时教学等需要自然对话节奏的场景里，用户体验提升显著。

未来方向：全双工多模态交互将成为下一代语音 AI 助手的标配架构，思考层插件化设计让不同推理能力的模型可以热插拔。

arXiv 2606.09186

AA-AgentPerf：业界首个 agentic 推理基准——以每兆瓦并发 Agent 数量衡量 AI 算力真实价值

现状：现有 AI 芯片和推理硬件的性能评测主要用 TPS（tokens per second，每秒生成的 token 数量）衡量，这个指标对单次对话有意义，但无法反映部署大规模 Agent 循环时的真实瓶颈——Agent 通常有 100-200 轮对话、序列长度超 100K token，和普通聊天对话场景完全不同。

解决方案：AA-AgentPerf（Artificial Analysis 推出的 agentic 性能基准）用真实编码 Agent 轨迹回放，在生产级优化（KV 缓存复用、投机解码（speculative decoding）、预填充/解码分离等技术）下测量系统极限。核心指标「Agents per Megawatt（每兆瓦并发 Agent 数）」把算力和能耗一起考量。首轮结果：NVIDIA Blackwell Ultra NVL72 领跑，比 Hopper 架构高 20 倍；测试基础模型为 DeepSeek V4 Pro。

价值：对需要部署大量并发 Agent 的企业（代码自动化、客服 Agent 等），这是比 TPS 更有决策参考价值的采购指标；能耗归一化也是数据中心层面的实际考量。

未来方向：agentic 推理基准将推动下一代 AI 芯片的设计目标从「单次推理速度」转向「单位能耗并发 Agent 容量」，影响整个 AI 基础设施的采购和建设逻辑。

DataFlow：LLM 驱动的数据准备框架——近 200 个算子，自然语言 spec 自动转可执行 pipeline，代码基准 +7%

现状：高质量训练数据的准备是 LLM 性能的关键瓶颈，但数据清洗、增强、过滤、格式转换的流程极度碎片化——不同任务（数学推理、代码、问答、SQL）需要不同算子，手动组合费时且难以复用。

解决方案：DataFlow 提供 PyTorch 风格的 pipeline 构建 API，近 200 个可复用算子覆盖文本、数学推理、代码、Text-to-SQL、agentic RAG（检索增强生成，把外部文档知识喂给 AI 的架构）、大规模知识提取六个域。DataFlow-Agent 组件把自然语言需求描述（spec）自动翻译成可执行的 pipeline：它先综合算子，再做 pipeline 规划，最后迭代验证。

价值：在代码基准上平均提升 +7%，在 MATH / GSM8K / AIME 数学基准上提升 1-3 分，在 Text-to-SQL 任务上执行准确率比 SynSQL 高 +3%；统一框架降低了跨任务数据准备的复杂度。

未来方向：数据准备的自动化将成为下一个被 Agent 大规模接管的 ML 工程环节，DataFlow 类框架有望成为 LLM 训练管线的标配组件。
