AI 方向观点

Guillermo Rauch（Vercel CEO）：开源权重模型已跑 Vercel 网关 29% 的 token，4月时只有 11%

Rauch 在 X 上给出了他看到的最新数字：经过 Vercel AI 网关（AI Gateway，即多模型统一接入层，类似让不同 AI 服务共用一个出入口）的 token 中，来自开源权重模型（Open-weight Models，指权重公开可下载的模型，如 Llama、Mistral、DeepSeek）的占比从 4 月的 11% 升至当前的 29%，不到三个月翻了将近三倍。

这不只是数字变化，而是企业选型逻辑的迁移信号：越来越多的生产流量不再只走 OpenAI 或 Anthropic，而是分散到可以自主部署、成本可控的开源权重层。Rauch 同期还提到 Vercel 最受欢迎的两个新功能是文件系统 API 的易用性和可观测性（Observability，即追踪 AI 调用行为的工具），暗示基础设施层的差异化竞争已经转向：不是谁家模型最强，而是谁的平台让多模型混用最省力。

当开源权重模型从补充渠道变成主流流量的近三分之一，「模型无关的基础设施」的赌注开始真正兑现。

Swyx（AI Engineer World's Fair 联合创始人）：大项目最优模型分工——sol ultra 规划、fable 5 批评、terra/sonnet 5 生产

Swyx 给出了他目前在「大型项目（Big Boy projects）」上的实际模型分工：用 GPT-5.6 Sol Ultra 做规划（高成本、高推理深度）、Claude Fable 5 做批评（外部视角审视方向）、Sonnet 5 / GPT-5.6 Terra Ultra / SWE-1.7 做具体生产（高性价比执行层），最终用 Devin Review 做代码审查。这是一套多模型协作流水线（Pipeline），每个环节匹配不同的擅长维度。

顶端用户已经不在选模型，而在设计 Pipeline——这是从单工具使用者到 AI 编排者的真实分水岭。

Ben's Bites：GPT-5.6 三档模型全面解析——Luna/Terra/Sol、5级思考强度 + Ultra、ChatGPT Work 与 Codex 合并

GPT-5.6 现已对所有用户开放。Ben's Bites 给出目前最清晰的实战指南：系列分三个档位，Luna（轻量快速）、Terra（均衡，接近 GPT-5.5 的替代）、Sol（最强，推理能力最深）。每个模型有五个思考强度档（light / medium / high / xhigh / max），另有 Ultra 模式——允许模型不受限制地启动 subagent（子代理，即模型自动派生出多个并行执行任务的实例），实测会极快耗尽每周用量配额。

实战配置建议：日常对话和生产力任务用 Luna xhigh；建站和创意工作用 Sol medium；硬任务放到后台 Agent 运行，而不是用 Ultra 实时消耗。新 ChatGPT Work 模式将原 Codex App 与 macOS ChatGPT 合并，界面统一但编程与非编程场景做了细节区分。新增「ChatGPT Sites」插件可直接生成可托管的带登录页面的网站。Computer Use（计算机使用，即 AI 直接操控鼠标点击界面）在 Sol medium/high 上表现出色，值得专门测试。

Ultra 模式的出现让 GPT-5.6 第一次有了真正意义上的「无限制 Agent 模式」，但代价是用量燃烧速度惊人——这是产品力跃升和配额设计矛盾的最直接体现。

人文与哲学

纯银「聊聊重启人生的话题」：人生的关键选择换哪条路结果都差不多，决定命运的是天赋、人格和家庭环境

犬校五月发起了一个话题：如果重启人生，你会做什么？纯银在回帖过程中产生了两个意外洞察。第一个洞察来自「换视角」：他平日频繁向内攻击自己——「所有人生目标都没实现，这辈子就这样了」。但把时间跨度拉到 30 年，从 19 岁到 49 岁，会发现他既年少成名（25 岁做到游戏媒体名编辑），也经历了网易、携程、Tap 的资深中层管理，创业七年，Gap Year 一年半走遍新疆云南西藏清迈，47 岁财务自由，49 岁接纳退休状态，感情稳定。「这么多项同时发生在一个人身上，其实是非常丰富的人生」——高光时刻很短，但组合起来足够丰富。

第二个洞察更结构性：回顾那些「重大选择」的节点——如果没有从某家公司负气辞职，如果把产品卖给了腾讯，如果没有跟技术合伙人散伙……放在 30 年跨度里看，不会有很大差别。「一个人决定命运的因素是：家庭环境，天赋，人格。」天赋会把人导向特定的职业轨迹，倔强和骄傲的人格让他无论如何都会在某个节点负气辞职，家庭环境既没有束缚他也没有助力他——这三个变量的组合，比任何一个「如果当初选了 A 而不是 B」的节点更有解释力。

「大概是五十而知天命的感悟。」纯银的结论不是消极宿命论，而是一种「从结构观察自己」的解放：不需要为每个错过的节点自责，因为人格和天赋早就在所有这些节点之前划定了你的轨迹。

纯银把「如果重启人生」从怀旧陷阱变成了自我考古——结论是，影响最深的不是那些可以选择的事，而是那些你生来就带着的事。

Garry Tan（Y Combinator CEO）：「绅士科学家时代回来了」

Garry Tan 发了一条只有一句话的推文：「Era of the Gentleman Scientist is so back。」绅士科学家（Gentleman Scientist）指 18-19 世纪那批用私人财力和纯粹好奇心驱动系统性科学探索的个人，如达尔文、法拉第——他们不依托机构，不受项目考核约束，靠自己的资源和热情推进严肃研究。

Tan 的判断是：AI 正在重新赋予个人这种能力。当一个人可以用 AI 快速搜集文献、设计实验、处理数据、生成代码，机构资源不再是进行高质量探索的必要条件。这呼应了 TLDR 今日另一篇文章「The Most Human Technology Ever Made」的核心论点：过去的创作和探索瓶颈是「积累多年技能、筹集资金、组建团队、获得许可」，AI 正在解除这些门槛。

「绅士科学家时代回来了」说的不是业余爱好者，而是有系统性探究能力的个人——AI 让这件事的成本第一次回到个人可承担的范围。

AI 进展

Long-Horizon-Terminal-Bench：46个长时程终端任务、密集奖励设计，揭示规划质量才是真正的 Agent 瓶颈

现状：现有终端 Agent 基准（Benchmark，即评测标准任务集）主要测短平快的任务，只记录最终对错，忽略中间过程——这导致评分稀疏，看不出 Agent 在哪个子步骤卡住。

问题：长时程任务（Long-Horizon Task，指需要跨越数十到数百步才能完成的任务）中，Agent 频繁在进行到一半时超时退出，即使主动停止也往往是因为自我验证能力弱而非真正完成。

解决方案：Long-Horizon-Terminal-Bench 构建了 46 个任务，覆盖实验复现、软件工程、多模态分析、交互游戏、科学计算等 9 类场景，每个任务分解为细粒度子目标，提供密集奖励（Dense Reward，即每完成一个子步骤都有信号，而非只有最终得分），捕捉局部进展。

价值：关键发现：单纯扩大推理规模（Inference Scaling，即让模型思考更多步）或拉长上下文窗口，对长时程任务帮助有限；规划质量（明确目标、追踪进度、做出有依据的停止决策）才是真正的短板。

未来方向：需要更好的规划机制、更强的记忆与进度追踪、更校准的「我该停了还是该继续」判断能力。

arXiv 2607.08964 · HuggingFace Papers

TurnOPD：按轮次分配在策略蒸馏资源，让长时程 Agent 训练更高效

现状：在策略蒸馏（On-Policy Distillation，一种用强模型「教师」监督弱模型「学生」训练的方法）中，KL 散度信号（衡量两个模型输出差异的指标）在多轮对话里严重向早期轮次偏斜，后期轮次的关键但稀少的决策点被忽视。

问题：标准 OPD 固定展开深度、对全轨迹的 KL 取平均，导致大量算力浪费在低价值的尾部轮次，而最重要的中后期决策点反而缺乏监督信号。

解决方案：TurnOPD 根据轮次级统计数据动态分配展开深度和 KL 聚合权重，优先训练信息密度最高的轮次，而非平均对待每个对话步骤。

价值：在长时程 Agent 任务上，TurnOPD 显著提升了训练效率，同等计算预算下达到更高的任务成功率。

arXiv 2607.05804

UniClawBench：主动式 Agent 的通用评测基准，无需明确指令即预判用户需求

现状：现有 Agent 基准大多测试「响应式」Agent，即给明确指令才执行——但真实工作中更有价值的 Agent 能主动预测需要什么并提前准备。

问题：主动式 Agent（Proactive Agent）缺乏统一评测框架，无法横向比较不同系统在真实世界任务上的主动性和准确性。

解决方案：UniClawBench 提供涵盖多类真实世界任务的统一基准，专门测量 Agent 在没有完整明确指令时的预判准确率和执行质量。

价值：为「下一代 Agent」的开发提供了一个更贴近真实使用场景的评测参照，促使模型不只会执行而且会预判。

arXiv 2607.08768

Data Analysis in the Wild：用真实数据集评测 LLM 数据分析能力，揭示现有模型对真实数据复杂性的盲区

现状：现有 LLM 数据分析基准（如 NL4DV、ChartQA）使用整洁规范的合成或精选数据集，测试出来的模型在实际数据分析场景中表现大幅下降。

问题：真实数据集有缺失值、类型混乱、命名不规范、跨列依赖等复杂性，现有模型对这些噪声极度脆弱。

解决方案：构建基于真实世界数据集的评测基准，覆盖表格问答（Table QA）和数据洞察生成（Table Insight）两类任务，系统测量模型在有数据复杂性条件下的实际能力。

价值：研究发现顶级 LLM 在真实数据上的表现显著弱于整洁数据，揭示了「数据清洗能力」和「数据理解鲁棒性」是下一步需要专门提升的方向。

arXiv 2607.06482

PACT：用特权轨迹协同训练多轮工具调用 Agent，弥补学生模型的局部视野盲区

现状：多轮工具调用 Agent（Multi-Turn Tool-Use Agent）训练中，学生模型只能看到自己产生的轨迹，而正确的工具调用序列往往需要在全局视角下才能判断——这造成训练信号不足。

问题：单纯模仿学习（Imitation Learning）的问题是：如果模型在某步产生了偏差，后续步骤就缺乏有效的监督信号，错误会累积。

解决方案：PACT（Privileged Trace Co-Training，特权轨迹协同训练）引入一个拥有完整轨迹视图的教师模型，在学生产生局部偏差时提供补充监督信号，使训练对偏差更鲁棒。

价值：在多轮工具调用任务上，PACT 相比纯模仿学习和标准强化学习基线显著提升了成功率，且对更长的工具链组合表现出更好的泛化性。
