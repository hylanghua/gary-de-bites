Aaron Levie（Box CEO）：AI 模型和 Agent 的所有进展，本质上都下游于 Eval 设计

Levie 今日在 X 上写下一句有深度的判断："Almost all AI model and agent progress is downstream from evals。" 翻译成产品语言：你的评测体系决定了你的模型往哪里走，而不是反过来。Eval（评测基准）不只是测量工具，它实际上定义了"进步"本身的方向——你在测什么，模型就在优化什么。这也是为什么不同公司的模型在不同 Eval 上各有长短：没有人在优化一个通用的"善"，每个人都在优化自己 Eval 里定义的"好"。

他同日分享了 Box 的另一个产品更新：HTML 内容现在可以在 Box 里直接预览、编辑和版本管理——这是 Box 把 Agent 生成的 Web 内容（AI 生成的报告、原型、嵌入式组件）纳入企业文件管理工作流的具体动作。这两条信息放在一起，说的其实是同一件事：你想让 AI 做对什么，你就得先精确定义"对"是什么，然后围绕这个定义建基础设施。Levie 说的是一个被行业低估的元命题：所有宣称"AI 进步了"的标题背后，都有人在决定"用什么标准量进步"——Eval 设计才是真正的竞争武器。

PlanBench-XL：大规模工具生态中，Agent 的长程规划能力在"阻断"面前崩溃

现状：越来越多的 LLM Agent（大型语言模型驱动的自主执行系统）需要在包含数百乃至数千个工具的生态系统中完成多步骤任务——比如一个电商场景下的采购 Agent，面对 1665 个工具、56 种数据类型，必须检索出正确的工具序列才能完成任务。现有评测大多在"工具列表已知、路径可见"的理想环境下测试 Agent，无法反映真实的工具生态复杂度。

问题：真实场景里，Agent 看不到全部工具列表，必须边检索边规划；中途还可能遭遇"blocker"——工具暂时不可用或路径被阻断，需要找到替代路径。现有评测对这两个维度几乎没有覆盖。

解决方案：PlanBench-XL 设计了一个零售领域的基准，包含 327 个查询、1665 个工具，要求 Agent 从大型工具库里检索、规划、并在路径受阻时重新规划；每个解决方案路径至少跨越 5 个工具调用步骤，考验跨步骤的中间值传递能力。

价值：结果相当严峻：GPT-5.4 在无阻断环境下达到 51.9% 准确率，但在最严苛的阻断条件下崩溃至 11.36%。当错误没有显性错误信号时，或当绕路路径更长时，Agent 失败率急剧上升。这意味着当前最强的商业模型，在真实复杂工具生态里的鲁棒性远低于实验室数据。

未来方向：对 Agent 框架的评测必须引入工具检索噪声和路径阻断场景；只在"完美信息"下评测的基准将低估部署失败风险。

arXiv 2606.22388 · GitHub

RecursiveMAS：多 Agent 系统通过潜空间递归循环提速 2.4 倍、减少 75% Token 消耗

现状：多 Agent 系统（Multi-Agent System，即多个 AI 实例相互协作完成任务的框架）通常以文本为中介：Agent A 输出文字，Agent B 读取后再输出文字。这种"文字接力"消耗大量 token（模型处理的文本单位，影响成本和速度），且每次文字转换都可能损失信息精度。

问题：把独立的 LLM 实例拼在一起，相当于让它们通过低带宽的文字频道传递思维——每一次转换都是一次有损压缩。现有多 Agent 框架缺乏让 Agent 之间直接交换更高密度信息的机制。

解决方案：RecursiveMAS 在 Agent 之间引入 RecursiveLink 模块：Agent 不再生成完整文本，而是把内部的隐向量状态（latent state，即模型计算过程中的中间数值表示）直接传给下一个 Agent，多轮迭代后才输出最终文本。不同模型家族的 Agent 通过这个机制形成递归协作闭环。

价值：在涵盖数学、科学、医疗、代码、搜索的 9 个基准上，RecursiveMAS 平均准确率提升 8.3%，推理速度提升 1.2 倍到 2.4 倍，token 消耗下降 34.6% 到 75.6%。

未来方向：多 Agent 系统的信息传输层将从"自然语言接力"演进为"隐空间流"，潜空间通信将成为高效 Agent 框架的标准配置。

Kairos：面向物理 AI 的世界模型框架，用混合线性注意力机制解决长程状态维护

现状：物理 AI（Physical AI，指能在真实物理世界中感知和行动的 AI，如机器人、自动驾驶系统）需要一个能持续追踪世界状态的模型——它必须记住几秒、几分钟前发生的事情，同时理解正在发生的事情，才能做出正确决策。现有世界模型（world model，即 AI 对外部世界运作规律的内部表示）大多专注于视频生成或单步推理，缺乏跨长时间维度的状态维持能力。

问题：全注意力机制（softmax attention）的计算成本随序列长度平方增长，在长程任务中不可持续；而简单的循环记忆会累积误差，随时间推移状态表示逐渐失真。这两个问题的共同结果是：物理 AI 的"记性"既贵又不准。

解决方案：Kairos 采用混合线性时间注意力（Hybrid Linear Temporal Attention）架构：滑动窗口注意力捕捉局部动态，扩张滑动窗口捕捉中程依赖，门控线性注意力（GLA）维护全局持久记忆。论文同时给出了数学证明，对该时序分解方法的误差累积建立了严格的理论上界。

价值：为物理 AI 提供了一个同时满足"长程状态持久"和"计算可扩展"的世界模型框架，并附有可验证的误差边界。

未来方向：物理 AI 的世界模型将不再只测生成质量，而是测长程状态一致性——Kairos 的误差上界框架将成为评测物理 AI 可靠性的参考标准。

ARIS：执行者与评审者来自不同模型家族，跨模型对抗协作驱动自主科研

现状：用 AI 自动完成科学研究（AI for Science）是当前热门方向，但现有系统大多用单一模型或同一模型家族的多个实例来完成从实验设计到论文撰写的全流程。同族模型往往有相关的偏差：都容易犯同样的错误，互相验证时形成"回音室"，审阅结果不可信。

问题：让 Claude 审阅 Claude 生成的代码，相当于让同一个人检查自己的盲点——错误被系统性掩盖。需要引入真正独立的外部视角。

解决方案：ARIS（Autonomous Research via Adversarial Multi-Agent Collaboration）强制要求执行者和审阅者来自不同模型家族：默认以 Claude 家族负责生成（代码、实验、草稿），以 GPT 家族负责审阅（评分、提出修改项）。三阶段证据-主张审计（evidence-to-claim audit cascade）在每个科研步骤上都要求执行方提供可查证的证据链，审阅方独立评分。系统包含 65+ 预设技能（Markdown 定义的可复用工作流）和 5 条端到端科研管线。

价值：通过跨模型对抗协作，ARIS 能捕捉同族自我审阅系统会系统性漏掉的错误；已有用 ARIS 完成的论文被顶级 AI 会议接收。

未来方向：未来严肃的 AI 辅助科研系统都将引入跨模型审阅机制——"让不同基座的模型互相挑战对方的输出"将成为自动科研流程的标准安全层。

MemORAI：动态加权 PageRank 驱动的图记忆框架，让 Agent 对话记忆精准跨越长程

现状：LLM 驱动的对话 Agent（如 AI 客服、AI 助手）在长期使用过程中面临一个根本问题：它们不记得你之前说过什么。要解决这个问题，现有方法要么把全部对话历史塞进上下文（成本极高），要么用简单的文本检索找相关片段（信息孤立，不能推理实体间关系）。

问题：人的记忆是结构化的：知道"某人喜欢某事"不够，还需要知道这个偏好和哪些其他事实相关，以及这个偏好在多次对话后是否发生了变化。文本向量检索无法捕捉这种关系网络。

解决方案：MemORAI 构建了三层机制：（1）双层压缩过滤，只保留与用户画像高度相关的信息；（2）多关系图，以实体-关系三元组存储记忆，追踪每条信息的来源（turn-level provenance）；（3）查询自适应子图检索，根据当前查询动态调整 PageRank（一种根据链接关系为节点打分的算法，原本用于网页排名，此处用于记忆片段的相关性权重）权重，让检索结果随问题类型变化。在 LOCOMO 和 LongMemEval 两个长期记忆评测基准上达到 SOTA。

价值：让 Agent 的长期对话记忆第一次有了"关系结构"和"来源可溯"两个维度，解决了纯向量检索的扁平化问题。

未来方向：图结构记忆将替代纯向量索引，成为个性化 AI 助手（需要跨多次对话保持用户画像一致性的系统）的标准记忆架构。
