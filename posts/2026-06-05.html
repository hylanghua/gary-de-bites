Alex Albert（Anthropic 研究）：Claude 开放工程任务成功率半年内从 26% 跳到 76%，Mythos Preview 已比人类更会纠偏

Alex Albert 发出 Anthropic 内部指标的公开摘要，把报告里最具体的数字讲清楚：80% 代码由 Claude 写；很多 Anthropic 研究员已经「好几个月没有手写代码」；工程师每季度合并的代码量是 2024 年的 8 倍；在开放性工程任务（即没有固定答案的任务）上，Claude 6 个月内成功率从约 26% 升至 76%；当研究人员在实验中走错方向时，Claude 有 64% 的时间给出了比该研究者实际下一步更好的建议。

Aaron Levie（Box CEO）：AI 不会消灭人的工作，它消灭的是工作的「上限」——新瓶颈是执行力和判断力

Levie 引用 Anthropic 报告里一段他认为最重要的话：「Anthropic 员工与高能力模型合作，产生了远超我们能够追求的新点子、新计划和新实验。识别并消除这些执行瓶颈的速度，可能会成为任何组织最重要的能力之一。」他的解读是：AI 降低了做更多事的门槛，但随之而来的是「我们能想到的比能做到的多得多」，最终的约束仍然是人——不是代码，而是判断、方向和执行。

纯银：拥抱 Agent，从入门到入门——场景驱动比信仰更重要，领域专业度比工程能力更重要

纯银坦承自己落后犬校同学「约半年多」才开始用 Agent：不是不愿意，而是「用不上，没必要」。最终打破这个心理障碍的不是技术大新闻，而是一个具体场景：用 Gemini 做旅行攻略时感知到 chatbox 能力不足，恰好 Gemini 在 4 月大幅降智，GPT-5.5 口碑又在这时回来——几个外力叠加，加上犬校同学定向说服「CodeX 全中文无代码，真的适合你」，才终于入水。他的归纳：「场景与动机 > 选择困难症 > 技术大新闻」是 Agent 上手的普遍驱动法则，有人带着团队推都推不动，缺的往往不是工具而是场景。

更有意思的是他对 Agent 本质的两点认知：第一，Agent 更聪明不只是因为模型更强，而是因为「以达成任务为目标」比「以延续对话为目标」显得更聪明，且 token 按量计价后模型不再抠门节约算力；第二，真正的生产力来源不是学习 Agent 操作技巧，而是把自己「原有的与 AI 匹配的能力迁移到 AI 里来施展」——他用多年做旅行攻略的品味细节（要求可考证历史年代、区分是否必须预约）直接迁移到 prompt 里，效果才真正好。半个月烧了 9.9 亿 token，但他坦承已经「严重影响睡眠」，决定暂停等旅行回来再找节奏。纯银这篇文章的价值在于细腻——不是「AI 很强你要用」，而是把中间的每一道心理和认知障碍都讲透了，这比任何 AI 教程都更有说服力。

NVIDIA Nemotron 3 Ultra：550B MoE 开放权重，55B 激活参数，1M 上下文，美国最强开源模型评分

现状：当前最强开源权重模型多集中在 70B-400B 参数范围，在代理任务长时运行和推理速度之间存在明显取舍；中国的 Kimi K2.6 此前保持美国以外最强开源模型地位。

问题：现有开源模型在长时间 Agent 任务（需要持续维持上下文、频繁工具调用的工作）中速度不够快，且激活参数过高导致推理成本偏贵。

解决方案：Nemotron 3 Ultra 是 550B 总参数、55B 激活参数的 MoE 模型（混合专家架构，每次推理只激活部分专家子网络），结合 Mamba-2（状态空间模型，擅长长序列建模）和 Transformer 的混合架构，支持 1M token 上下文窗口，在 20T token 上预训练，使用 NVFP4（NVIDIA 的 4-bit 低精度训练格式）。在 Artificial Analysis Intelligence Index 上得分 48，是美国所有开源模型中最高。推理速度 400+ token/s，当天在 vLLM、Together、Fireworks、Ollama 等平台全面上线，采用 OpenMDW 1.1 协议，商业使用免费。

价值：美国开源生态在对齐能力和推理效率上的最高水位线，同时公开了训练数据、奖励模型检查点和量化变体。

未来方向：Mamba-Transformer 混合架构将在长上下文 Agent 模型上成为标准设计路径；NVFP4 规模预训练是低精度训练进入新规模区间的信号。

ChatGPT Dreaming：用「做梦」机制重构长期记忆——从孤立事实到连贯档案，召回准确率 +15pp

现状：ChatGPT 现有记忆系统存储离散事实片段，随时间积累后产生冗余和过时信息，准确率随使用时间递减。

问题：孤立事实记忆无法捕捉用户偏好的演变，也无法处理相互矛盾的历史记录；检索时的精度随记忆条目增多而下降。

解决方案：「Dreaming」在非活跃时段对历史对话做整合处理（类似人类睡眠时的记忆巩固），把零散片段提炼为带时效标签的连贯档案；引入「记忆准确性」和「跨时间一致性」两个新评估维度，内部测试中事实召回从 67.9% 升至 82.8%，偏好遵从度从 55.3% 升至 71.3%，跨时间准确性从 52.2% 升至 75.1%。用户可在专属页面实时查看、编辑或清除所有记忆。

价值：把 ChatGPT 从「每次对话都要重新解释自己」向「持续了解你的助手」推进了一大步；记忆可审计和可编辑是信任设计的重要一步。

未来方向：基于「Dreaming」的主动记忆整合将成为下一代对话助手的标配机制，取代被动的片段式记忆存储。

Ares：LLM Agent 的自适应推理预算选择——按步骤动态分配思考量，低成本保高性能

现状：具备「think-time」（推理前先思考的机制，类似 o1/R1 模型的链式推理）能力的 LLM 在准确率上表现出色，但每一步都分配相同的深度思考会造成大量计算浪费。

问题：多步骤 Agent 任务中，不同步骤的复杂度差异很大——简单步骤不需要深度推理，但固定 token 预算强迫它「过度思考」；降低全局预算则影响难步骤的质量。

解决方案：Ares（Adaptive Reasoning Effort Selection）在每个 Agent 步骤前动态判断所需的推理努力等级，对简单步骤快速通过，对复杂步骤分配充足 think-time，在多步骤 Agent benchmark 上显著降低总推理成本，同时保持接近全预算的性能。

价值：让 think-time 模型在实际 Agent 部署中具备经济可行性——推理成本降低而性能不显著下降，是 Agent 成本控制的实用方案。

未来方向：步骤级别的动态推理预算管理将成为高性价比 Agent 系统的标准组件。

MARBLE：多模态空间推理与规划基准——强调推理轨迹的质量，而非仅最终答案

现状：现有多模态推理基准（视觉 + 语言的综合测试集）主要评估最终答案是否正确，对模型到达正确答案所经历的推理过程不作要求。

问题：模型可以通过捷径、统计偏差或直觉猜测得到正确答案，而不是真正推理；在空间规划类任务（需要理解物体位置、路径和方向关系的任务）上，表面的准确率掩盖了推理过程的不一致性。

解决方案：MARBLE 构建了一套包含详细黄金标准推理轨迹的多模态空间任务集，同时评估最终答案和中间推理步骤的一致性；当前最强的多模态模型在这个基准上频繁出现推理步骤错误但最终答案碰巧正确的情况，揭示了现有 VLM（视觉语言模型）的空间推理脆弱性。

价值：提供了一个检验 VLM 真实空间推理能力的更苛刻标尺，有助于识别当前模型的系统性弱点。

未来方向：空间规划推理能力将成为具身 AI（机器人、AR 应用）的核心评估维度，轨迹质量评估比答案准确率更能预测真实部署效果。

arXiv 2506.22992

Scaling Test-Time Compute for LLM Agents：把「长思考」从单轮问答扩展到多步 Agent 任务

现状：Test-time compute scaling（推理时计算扩展，即通过在输出前花更多算力思考来提升准确率）在数学和编程问答上已经验证有效，代表模型是 o1 和 R1 系列。

问题：多步 Agent 任务（需要连续决策、工具调用、环境交互的任务）与单轮问答有本质差异：错误可以累积、上下文随步骤增长、工具调用结果不可预测，原有的 test-time compute 理论不能直接平移。

解决方案：研究系统分析了长思考模型在 Agent 场景中的适用条件和失效模式，提出了在 Agent 多步决策链上分配 test-time compute 的框架，并通过实验验证了在不同任务类型和步骤长度下的有效性边界。

价值：为 Agent 系统的「思考量配置」提供了理论支撑，有助于从业者判断何时增加推理时算力真的有帮助、何时反而带来噪声。

未来方向：Agent 任务的推理时扩展将成为独立于模型训练的主要性能提升手段，test-time compute 预算优化是下一个重要工程方向。
