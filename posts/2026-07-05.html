新闻速递

Claude Science 正式发布：Anthropic 入局药物研发，真实目标是把平台卖给大药厂

Anthropic 于 6 月 30 日推出 Claude Science，一款面向生命科学研究者的 AI 工作台（工作站软件），内置 60+ 个针对基因组学、蛋白质组学、结构生物学和化学信息学的预配置分析工具，目前处于 beta 阶段，并向入选项目提供最高 3 万美元的使用额度。与此同时，Anthropic 宣布将自行启动针对罕见病的临床前药物研发项目。

但这并不意味着 Anthropic 想成为药企。Every 的分析一语中的：这是「卖铲子」（sell the shovels）策略——用最难的真实问题测试自家 AI 的极限，修补评估与验证流程中的瓶颈，然后把打磨好的平台卖给大药厂。生物系统的反馈周期以天计算，不像软件可以秒级验证；谁能在这里建立可靠的工作流，谁就能拿走整个市场。Anthropic 不是在做药，它是在用做药来测试工具。

Sonnet 5 发布一周：Every 团队坦言没人真正在用它；Fable 5 同周回归才是真正的亮点

Anthropic 本周出了两个模型，结果截然不同。Sonnet 5 定位「万能中档」，但 Every 的测评直接说：价格、速度、智力三项各有更优替代，当你需要省钱时选 Haiku，需要顶配时选 Opus 4.8 或 Fable 5，Sonnet 5 夹在中间显得尴尬。与之对比，Fable 5 在周四重新上线，Fable 在约三小时内从一个 prompt 出发重建了 Every 的文档编辑器 Proof，团队集体表示「终于回来了」。

同期还有一个值得记录的失败案例：AI 仍然无法可靠地生成企业级 PPT。Every 的顾问团队尝试自动化 PPT 制作，搭建了一套 24 个技能节点（skill）的流水线，每份幻灯片成本约 62 美元，效果依然不稳定，且并不适合大多数团队。最难的部分，是「你想说什么」，这 AI 替代不了。Sonnet 5 是一款为所有人设计的模型，因此对任何人都缺乏惊喜。

AI 方向观点

Simon Willison：新一代模型调外部工具时会「自造字段」，老模型没这问题

Simon Willison 记录了一个有意思的回归问题：Opus 4.8 和 Sonnet 5 在调用 Pi 等第三方工具时，会自动添加工具定义里根本不存在的字段（invented fields），而老模型不会这样做。Armin 提出了一个理论：Anthropic 用 RL 专门训练了模型对 Claude Code 内置工具（edit、search-and-replace）的调用能力，这种训练「泄漏」到了其他工具实现上，导致模型对非原生工具也套用了错误的期望。

这个发现的意义不只是 bug 报告。对于正在用第三方工具调用（tool use）框架搭建产品的开发者来说，升级到更新模型反而可能引入新的不稳定性。「更聪明」的模型不等于「更安全的工具调用」。RL 的优化目标越具体，训练出的习惯就越难被泛化控制——这是新一代模型落地时值得持续监控的副作用。

Simon Willison

Nan Yu：AI 没有让你更少抓狂，只是把抓狂的对象换了

Nan Yu 的观察很准：手写代码的时候，他不停地骂自己；现在和 AI 协作，他骂 AI 的 output。挫败感的总量没有变，只是对象从「自身的能力极限」变成了「外部工具的输出质量」。

但这其实是一种真实的进步。骂外部工具的心理成本，远低于骂自己的能力——前者是可以替换的工具问题，后者是很难摆脱的自我怀疑。AI 把认知摩擦从「我够不够好」转移到了「工具够不够准」。这种情绪转移比生产率提升更低调，但可能同样重要。

Thomas Sottiaux（AI 研究者）：公开征集「Codex 仍然做不好什么」

在 Codex 已被大量开发者视为日常工具的背景下，thsottiaux 仍在系统地追问：Codex 让你感到意外的盲区是什么？这个问题本身就是信号：即便是熟练用户，也在持续发现 agent 工具的认知边界。每一个真实盲区，都是下一个产品或 fine-tune 方向的切入点。问「做不好什么」比问「能做什么」，对产品判断的价值更高。

产品与商业

Every：每一个 AI 策略都暗含四个赌注，能说清楚的团队才能在出错时快速调整

Every 的 CTO Dan Pupius 提出了一个简洁但有力的框架：任何 AI 策略，底层都隐含着四个创始人通常不会明说的赌注——token 成本会持续下降、模型能力会继续提升、你不会被特定供应商锁死、监管环境不会突然收紧。这四个赌注不是路线图，是假设。

问题在于，当其中任何一个假设出错，没有明说过赌注的团队很难快速调整，因为他们根本不知道自己的策略建立在什么之上。能说清楚「我们在赌什么」的团队，才有可能在市场反转时跑得比别人快。AI 策略的底牌是赌注，不是路线图：能说清楚自己在赌什么的团队，才能在形势反转时快速调整。

人文与哲学

Wisereads / David Brooks：AI 时代三种人——最终稀缺的不是智识，是意志力

《纽约时报》专栏作家 David Brooks 把 AI 时代的人分成三类：被动外包者（让 AI 替自己思考）、混合型（偶尔借助 AI）、主动摔跤者（刻意用 AI 来磨砺自己的判断力）。他的核心论点是：当智识变得充裕且廉价，人类真正稀缺的资源不再是「能想明白多少」，而是「愿意花力气去想」的意志力（volition）。

「做出区别的人，不是那些追求放松、用 AI 少干活的人，而是那些追求进步、主动与 AI 摔跤来发展自身判断力的人。」这个分野不是能力的分野，而是姿态的分野。被动外包者短期内轻松，但认知资本在悄悄流失。AI 时代最大的分层，将是「愿意费力」和「不愿意费力」之间的分层。

Wisereads · The Atlantic

Wisereads / Cal Newport：和 AI 长聊是一种情感自欺——大脑会为空无一物的地方模拟出一个心智

Georgetown 大学教授 Cal Newport 在重访「数字极简主义」时给出了一个令人不安的观察：当人们与 AI chatbot 进行长时间对话，大脑会在另一端「模拟出一个真实存在的心智」——而那个心智并不存在。这是大脑处理社会互动的自动化机制在被系统性地误用。

他的用词是「情感欺诈」（emotional fraud），不是因为 AI 有恶意，而是因为大脑的社交回路无法区分「真实的另一个人」和「能流畅回应的语言模型」。在 Agent 大量普及、人与 AI 交互时间骤增的今天，Newport 的这个警告比之前任何时候都更值得认真对待。和 AI 对话越流畅，被误认为「真实连接」的风险就越高——这是一种隐形的认知陷阱。

AI 进展

Program-as-Weights：把自然语言函数规格「编译」成轻量神经适配器

现状：每次调用大模型处理一个任务，都需要把完整 prompt 和上下文传入，推理成本随任务数量线性增长。

解决方案：Program-as-Weights（PAW）提出一种新范式：用一个 4B 参数的「编译器」模型，把自然语言函数定义一次性编译为紧凑的神经适配器（parameter-efficient adapter），之后每次调用只需运行轻量的 0.6B「解释器」模型。编译在函数定义时只发生一次，多次调用均复用同一适配器。

价值：0.6B 解释器执行 PAW 程序，性能匹配 32B 模型直接推理，但推理显存仅为其 1/50，可以 30 tokens/s 的速度在 MacBook M3 上离线运行。对需要高频调用固定功能函数的应用场景（如分类、格式化、过滤），这意味着数量级的成本下降。

未来方向：重新定位大模型的角色：不是每次任务的「解题者」，而是生产可复用轻量工具的「工具制造者」。

arXiv 2607.02512 · HuggingFace

WebSailor：7B 开源 web agent 在复杂信息检索任务上逼近 DeepResearch 等专有系统

问题：在极度不确定的大规模信息检索任务中（如 BrowseComp 基准），开源 agent 与 DeepResearch 等专有系统之间存在巨大能力差距。差距的核心不是参数量，而是「在不确定性中系统压缩搜索空间」的推理模式。

解决方案：Tongyi Lab（阿里巴巴）提出 WebSailor——通过结构化高不确定性任务生成、RFT 冷启动和新型 RL 算法（DUPO，Duplicating Sampling Policy Optimization）训练开源模型，使其习得上述推理模式。

价值：WebSailor-7B 在 BrowseComp-en 达到 6.7% 准确率，超越大量基于 32B 模型的开源 agent。对于需要可控、可本地部署的 web 检索 agent 的场景，这是一个里程碑式的开源基线。

arXiv 2507.02592 · HuggingFace

MemoryAgentBench：首个系统评估 LLM Agent「记忆能力」的基准（ICLR 2026）

问题：现有 agent 基准主要评估推理、规划和执行，「记忆」——agent 如何在长期交互中记住、更新和检索信息——几乎没有独立的评估框架。

解决方案：UC San Diego 团队提出 MemoryAgentBench，定义了 agent 记忆的四项核心能力：准确检索（retrieve accurately）、测试时学习（learn at inference time）、长程理解（long-range comprehension）、选择性遗忘（selective forgetting）。基准通过将现有长文本数据集转化为多轮交互格式构建。

价值：对于需要持续运行、跨会话学习的 agent 来说，记忆能力是决定长期上限的关键维度。这是第一个把这个维度系统量化的工具。

arXiv 2507.05257 · ICLR 2026

Are Online Skills Worth Their Tokens？同等 token 预算下，「记忆+技能」模块通常跑不赢多走几步的普通 actor

问题：Web agent 研究中流行给基础 actor 模型加装「在线记忆」或「技能模块」来提升表现，但这些模块本身消耗大量 token，这个成本很少被计入比较。

解决方案：该论文在相同总 token 预算下，将 AWM、ASI、ReasoningBank 三种增强方法与「把同等 token 全部用于 actor 多推理几步」的 baseline 进行比较，覆盖 WebArena 三个领域、三个模型（Gemini 3 Flash、GPT-5.4-mini、Qwen 3.6-27B）。

价值：结果：vanilla baseline（多走几步）在综合成功率上匹配甚至超过三种增强方法，且往往 token 总量更少。技能模块在特定领域有用，但它们的「表观收益」往往来自不公平的预算比较。在评估 agent 增强方案时，「总 token 预算」是不可绕过的控制变量。

arXiv 2606.15017

Act As a Real Researcher：最强配置仅达 68.3% 成功率——frontier agent 离真正替代科研人员还差什么？

现状：AI agent 在通用编码、信息检索等任务上表现已接近或超越人类，但「真实科研工作流」的评估框架远未成熟。

解决方案：西安交通大学团队推出 AARR benchmark，测试 frontier LLM 和 agentic 工具是否能模拟真实科研人员在细粒度场景下的专业性、严谨性和科学判断——而不只是宏观执行能力。

价值：最强配置（Claude Opus 4.7 + Mini-SWE-Agent）仅达 68.3% 成功率，频繁忽略对人类研究者来说一眼可见的细节。系统性短板集中在三处：领域敏感性（domain sensitivity，跨领域判断的上下文理解）、研究伦理、细粒度科学判断。agent 能「执行」科研任务，但离「理解」科研工作仍有系统性差距。
